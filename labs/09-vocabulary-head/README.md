# 实验 09 · 把 256 路词表投影迁到 NPU

保持前馈升维和 Q/K/V 均使用 H1，只切换输出层。用训练样本校准激活尺度，按输出通道量化权重。逐一输入 64 个留出提示，每个提示在同一地址连续请求两次，记录冷、热首字节、后两个字节和完整请求。

## 运行

从仓库根目录执行 `make lab09`。RV32IM GCC、Verilator、C++、CPU PyTorch。首次运行会重训实验 08 的宽度 32 模型。 [环境与完整复现顺序](../../docs/EXPERIMENTS_09_23.md#复现环境)

## 交付与验收

先在验证集核对回复，再核对测试集自由生成的三个字节。三条路径各须答对 64/64，量化回复困惑度最多上升 1%。核对冷、热全部 logits，主机与客体最大误差不超过 0.0001，设备和整数 CPU 输出逐位相等。总线须出现 24,576 条词表分块命令。破坏 CRC、重算 CRC 但把词表尺度清零，两次均须零命令、零 DMA、零缓存写，随后正常包必须恢复生成。

词表 FP32、CPU INT8、NPU INT8 的冷完整请求均值分别为 25,799,198、16,289,431、15,985,687 拍。输出层量化加阵列相对浮点减少 38.0%，阵列相对同量化 CPU 再减少 1.86%。后两个生成步合计分别为 8,410,119、3,949,079、3,746,583 拍。两个整数路径使用同一份 31,728 B 包，浮点包为 42,988 B；冷启动收益包含包校验成本的变化。

## 迁移练习

从一次热请求的 mmio、counts、uart 日志中找到最后一个词表块，对照输出地址、四路结果和最终字节。
