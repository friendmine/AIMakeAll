# 实验 08 独立试读任务单

请一位未参与本实验实现的学习者在自己的环境完成。可使用本地项目副本和下列说明。先填写预测，再打开报告或实验手册中的成绩单。保留第一次运行失败和求助的记录。

1. 给定七字节提示 `Rddd=f>`，模型应根据标志位 0/1 分别生成 `no`/`ok`，随后输出换行。候选前馈宽度为 32 和 24，Q/K/V 可用 RV32 浮点、RV32 INT8 或 NPU INT8。单包限 42 KiB，可写内存含栈限 32 KiB，阵列操作数存储限 256 B。合格候选须在 64 条中答对至少 61 条、比同宽全浮点少至多一条，回复困惑度不超过浮点的 1.01 倍且优于 bigram。请先独立写下两种标志位的输出、提示与解码各自的瓶颈、你的首选及一项落选理由，然后才查看项目的预测和验收结果。
2. 在已安装 make、CPU PyTorch、Verilator、C++ 编译器和带 newlib 的 RV32IM GCC 的机器上，从新的构建目录运行以下命令。从索引 2–31 中选一个尚未演示的测试编号。每个编号的两条记录只相差标志位。把下方的 2 换成你的索引。

   ```sh
   make byte-transfer BYTE_PAIR=2 BYTE_BUILD=build/reader08/byte PROJ_BUILD=build/reader08/tile GEN_BUILD=build/reader08/soc
   ```

3. 查结果报告。从实际设备命令指出一处提示与逐字节生成的差异，用周期和质量重新评判自己的两种方案。再把可用单包空间从 42 KiB 收紧到 41.5 KiB，写下可部署的候选和理由。
4. 交付以下个人记录和生成的 `report.json`。可仅使用自选代号。报告保存在 `build/reader08/byte/pair-2/`（目录编号随选择变化）。
