# 实验 15 · 导出可执行的模型计划

沿两层模型的执行顺序提取九个线性算子，输出 JSON 描述符和含浮点参数、量化权重及逐通道尺度的二进制包。按四输出通道打包，记录每项偏移、形状和 K 分块上限；归一化、注意力、激活和取最大值保留在 CPU。

## 运行

从仓库根目录执行 `make lab15`。两种训练模型、CPU PyTorch、Verilator、C++。 [环境与完整复现顺序](../../docs/EXPERIMENTS_09_23.md#复现环境)

## 交付与验收

对象集合、图顺序、形状、张量区间与哈希须合法。两个模型的宿主计划与 RTL 都要逐项复现基准。对摘要、截断、缺层、错形状、重叠、越界及缺参数的七种坏包须在执行前拒绝。

宽度 48 / 40 的载荷分别为 74,240 / 73,088 B。每个模型对三个输入字节核对 768 个输出分数。编译器当前接收本课程两层 ByteLM 的计算图。
