# 实验 20 · 用自训练模型选择并执行工具

从实验 10 的宽度 48 检查点微调，以一个输出字节选择计算、限定条目查询或实验成绩读取。执行器校验结构化参数并返回结果。相同的 30 个任务分别交给规则、纯 RV32 模型和 NPU 模型，训练数字 10–69、测试数字 80–89。

## 运行

从仓库根目录执行 `make lab20`。实验 18 的 CPU 训练和 PicoRV32 RTL 环境。 [环境与完整复现顺序](../../docs/EXPERIMENTS_09_23.md#复现环境)

## 交付与验收

模型至少答对 27/30，道数按实际工具返回值计；CPU/NPU 选择逐项相同。记录模型周期、主机端耗时和工具轨迹，拒绝未知工具、错误参数和超范围条目。

三个策略均答对 30/30。CPU / NPU 选择工具平均用 35,760,622 / 30,941,652 个 RTL 拍。本任务每次只允许一次工具调用，工具在宿主执行，测试沿用训练中的三组意图词。

[本机已验证的报告](verified-run.json) · 新运行的报告位于 `build/tool-agent/report.json`。
