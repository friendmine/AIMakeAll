1. 选择 README 演示之外的 3–8 个 ASCII 字节作为提示，指定三个生成步。在看到周期前，写下质量门槛、权重字节预算、首选模型与阵列，以及可能落选的组合。
2. 从同一训练配方生成两个候选；核对训练语料摘要、测试集隔离和两个包的真实大小。给出两个硬件上的输出、命令数、提示词和各生成步的周期。
3. 对新提示，在宿主与两种硬件核对 768 个输出分数；指出一处可说明阵列接口行为的总线事件。
4. 注入一次布局或尺度错误，找出首次分歧的算子、位置、参考值与观察值。纠正后用相同提示复测。
5. 回传独立运行日志、预测原件、落选方案和第一次卡住的位置。记录是否需要作者提示及耗时。
