# 实验 16 · 测量 KV 缓存的容量与重算代价

在完全相同的量化计划上，对 4、16、48、88 字节前缀各生成五步。逐步比较完整前缀重算与保留两层 K/V，每条路径重复五次并保留各步宿主耗时中位数。

## 运行

从仓库根目录执行 `make lab16`。CPU PyTorch。 [环境与完整复现顺序](../../docs/EXPERIMENTS_09_23.md#复现环境)

## 交付与验收

每步选中的字节一致，最大 logit 误差低于 0.005；缓存字节数符合 2×层数×有效位置×嵌入宽度×4。记录线性算子处理的行数与宿主时间。

每个有效位置需 512 B。88 字节前缀加四次追加达到 47,104 B 的持久 KV；重算路径的持久 KV 为零。报告不计 PyTorch 临时张量，宿主纳秒只能在相同环境比较。

[本机已验证的报告](verified-run.json) · 新运行的报告位于 `build/kv/report.json`。

## 迁移练习

用 16 字节前缀预测每层缓存大小，比较提示词阶段和后续四步的耗时变化。
