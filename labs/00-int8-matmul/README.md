# 实验 00：从 INT8 矩阵乘法到硬件 MAC

## 学习目标

理解神经网络线性层的基本计算，以及 Python 的无限精度整数与硬件定宽整数的区别。完成后能够手算一个矩阵元素，并解释负数、溢出、复位和使能的效果。

## 原理

对 A[M,K] 和 B[K,N]，输出 `C[i,j] = Σ A[i,k] × B[k,j]`。MAC 指 multiply-accumulate，即每一步把一个乘积加入累加器。一个 MAC 可以跨多个周期完成点积；多个 MAC 才能并行处理更多输出。

有符号 INT8 范围是 -128…127，因此 `(-128) × (-128) = 16384`，乘积至少需要有符号 16 位。累加使用 32 位。本项目明确选择回绕：`2147483647 + 1 → -2147483648`。神经网络量化需要合理缩放避免溢出，回绕本身不是量化算法。

## 运行

从仓库根目录运行，需要 Python 3.10+：

```sh
make demo
make test
```

`make demo` 的结果：

```text
A = [[1, -2, 3], [4, 0, -1]]
B = [[2, 1], [-3, 2], [1, -4]]
C = [[11, -15], [7, 8]]
```

例如第一项 `1×2 + (-2)×(-3) + 3×1 = 11`。参考实现位于 [reference/int8.py](../../reference/int8.py)。这是数值规范，不用于展示推理性能。

## 硬件实验

本机若有 Verilator、C++ 编译器和 make：

```sh
make rtl-test
```

最后应看到 `PASS: all INT8 pairs, hold, clear, reset, INT32 overflow`。RTL 位于 [mac_int8.sv](../../hardware/rtl/mac_int8.sv)，测试台位于 [mac_int8_tb.cpp](../../tests/mac_int8_tb.cpp)。

每个时钟上升沿：clear 为 1 时清零；否则 enable 为 1 时累加；否则保持。rst_n 拉低会异步清零，优先级最高。测试穷举 65,536 对 INT8 输入，并验证累加溢出、保持、clear 优先级与非零状态复位。

目前 RTL 是单 MAC，没有总线、矩阵控制器、CPU、QEMU 或模型。Python 测试验证完整 GEMM；RTL 测试验证 MAC，不能据此宣布矩阵 NPU 已完成。

## 常见问题

- `verilator: command not found`：可以先完成 Python 实验，安装开放仿真工具后继续。
- 负数结果错误：检查是否声明 signed，以及乘积进入累加器前是否符号扩展。
- 矩阵维度不匹配：A 的列数必须等于 B 的行数。
- Python 与硬件极值不一致：检查是否按 32 位回绕；Python 默认不会自动溢出。

## 练习

1. 手算输出的其余三个元素，再修改输入验证。
2. 把 enable 拉低多个周期，说明为何累加器应保持不变。
3. 计算 K=256 时的累加绝对值上界，判断是否可能溢出 INT32。
4. 设计饱和累加与回绕累加的不同预期结果；不要在没有修改规范的情况下替换项目语义。
