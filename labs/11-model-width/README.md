# 实验 11 · 在相同训练预算下选择前馈宽度

把前馈宽度从 48 改为 40。固定字节词表、文档划分、初始化种子、每步样本和总训练量。分别独立训练，只依据验证困惑度选型，再公布留出测试成绩。

## 运行

从仓库根目录执行 `make lab11`。同实验 10。 [环境与完整复现顺序](../../docs/EXPERIMENTS_09_23.md#复现环境)

## 交付与验收

两份报告的拆分、种子、步数、语料哈希和训练量必须一致；交付参数量、验证和测试困惑度及自由生成样本。

宽度 48 / 40 的验证困惑度分别为 7.7624 / 8.1105，测试为 8.3685 / 8.6022。按本实验的质量目标选宽度 48；实验 19 再检验收紧内存预算后是否会改选。

[本机已验证的报告](verified-run.json) · 新运行的报告位于 `build/language/comparison.json`。
