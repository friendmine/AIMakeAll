# 实验 13 · 验证两个请求源共享 DMA 队列

两路请求以轮转仲裁进入四项 FIFO，外部目标可施加背压。用独立队列记分板和 RTL 断言检查同拍入队/出队、满队列、非法目标地址和运行中复位。

## 运行

从仓库根目录执行 `make lab13`。Verilator、C++。 [环境与完整复现顺序](../../docs/EXPERIMENTS_09_23.md#复现环境)

## 交付与验收

每项已接收请求只能提交一次或被复位取消；停顿中保持输出稳定；两路竞争时按轮转发放；排空后接收数等于提交数加取消数。交付波形 trace.vcd 和计数报告。

2,048 拍内接收 1,466 项，向目标提交 1,459 项，复位取消 7 项；565 拍背压，1,277 次同拍入队与出队。目标端识别 86 次越界访问。这里验证的是独立仲裁器，整机实验使用各自既有总线。

[本机已验证的报告](verified-run.json) · 新运行的报告位于 `build/dma-arbiter/report.json`。
