# 实验 14 · 比较两种供数电路的周期、面积与时序

固定同一 Q/K/V 投影和外部协议。H1 先写入两个存储体再读回；流式实现保持当前激活，在权重达到时做乘加。对两者回放九行及单行输入，并插入握手停顿。使用同一个 TT 25°C、1.8 V 标准单元库，时钟周期 50 ns，I/O 延迟 1 ns。

## 运行

从仓库根目录执行 `make lab14`。Verilator、C++、CPU PyTorch、Yosys、OpenSTA、SKY130 HD Liberty。可设 AIM_LIBERTY 和 STA。 [环境与完整复现顺序](../../docs/EXPERIMENTS_09_23.md#复现环境)

## 交付与验收

输出逐项匹配整数参考；流式单行周期应下降。保留两份综合网表、面积、时序报告、库哈希和带停顿的波形。

提示词投影 7,920 → 5,544 拍，单行 2,448 → 1,656 拍。映射单元面积 149,768.64 → 75,537.45 µm²，综合后建立时间裕量 30.85 → 39.52 ns。这里的面积限于阵列顶层，时序来自布局布线前的网表。

[本机已验证的报告](verified-run.json) · 新运行的报告位于 `build/array-design/report.json`。
