# 实验 12 · 让真实模型投影跨越阵列边界

抓取实验 10 的 Q/K/V、前馈降维和词表层真实张量，比较 K 上限 13 和 32，覆盖 M=1/5、N 的尾块与 K=48。用宿主累加跨 K 分块的 INT32 部分和。

## 运行

从仓库根目录执行 `make lab12`。CPU PyTorch、Verilator、C++。 [环境与完整复现顺序](../../docs/EXPERIMENTS_09_23.md#复现环境)

## 交付与验收

逐微块对照独立整数点积，完整结果再次逐项比对；报告 shape、指令数、有效 MAC、输入输出字节和周期。

12 组组合合计核对 8,098 个部分和。对 5×48×32 的降维，K 上限 13 / 32 各发 64 / 32 条命令，分别耗时 3,072 / 2,688 阵列拍。

[本机已验证的报告](verified-run.json) · 新运行的报告位于 `build/matrix-tiles/report.json`。
