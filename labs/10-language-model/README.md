# 实验 10 · 从随机权重训练自然语言字节模型

使用 CPython 3.11.7 内置英文帮助文本。全局去重后按主题分为训练、验证、测试，训练窗口独立采样；bigram 只用训练集计数。模型为两层、四头，嵌入维度 32，前馈宽度 48，上下文 96。用固定种子训练 1,600 步，在半程保存并恢复模型和 AdamW 状态。

## 运行

从仓库根目录执行 `make lab10`。CPU 版 PyTorch；运行不需要下载语料。 [环境与完整复现顺序](../../docs/EXPERIMENTS_09_23.md#复现环境)

## 交付与验收

续训的第一步与连续训练权重逐位一致；改变后半段输入不能影响前半段输出；验证、测试困惑度均优于 bigram。交付训练曲线、数据划分、语料摘要、检查点与生成样本。

34,784 个参数，训练预算 1,228,800 个目标字节。验证困惑度 7.7624 对 12.2389，测试 8.3685 对 13.2487。模型从 “The ” 续写出 “argument is the called t”。这些数字衡量这批英语技术文本上的字节预测。

[本机已验证的报告](verified-run.json) · 新运行的报告位于 `build/language/metrics-48.json`。

语料取自 CPython 3.11.7 标准库 pydoc_data.topics，快照保留 72 个主题，其中 71 个长度满足训练窗口，按训练 55、验证 8、测试 8 划分。用同版解释器运行 `python3 labs/10-language-model/corpus_source.py` 可从标准库逐段核对随仓库分发的快照。[语料许可](PYTHON-LICENSE.txt)

## 迁移练习

从测试主题取一个新的前缀，记录下一字节的前三个候选和续写，再检查模型在哪一步偏离原文。
