# 实验 21 · 在 Linux 客体枚举并驱动 PCIe 投影设备

在 q35 虚拟机内用 sysfs 发现 PCIe BDF、启用总线主控并映射 BAR0。客体锁住一页 DMA 内存，提交宽度 48 语言模型最后一层的真实 INT8 激活和常驻权重；每命令算四个 INT32。拒绝 K=33，注入保持忙碌的故障，在期限到达后复位并重试。

## 运行

从仓库根目录执行 `make lab21`。Go、QEMU 9.2.4 源码和构建依赖、CPU PyTorch、Alpine x86_64 内核。 [环境与完整复现顺序](../../docs/EXPERIMENTS_09_23.md#复现环境)

## 交付与验收

错误命令的完成计数须保持不变；非法 DMA 对齐或地址也应被拒绝；复位后正常请求须完成。12 个请求各提交 64 次，全部 256 项输出与独立主机点积逐字节一致；保留串口和按请求计时。

客体识别到 0000:01:00.0；每请求 DMA 读取 10,240 B、回写 1,024 B。设备使用 Linux 用户态驱动和轮询；在这台隔离教学虚拟机中运行，无需物理设备。
