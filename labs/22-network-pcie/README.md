# 实验 22 · 对照直接 PCIe、回环和双虚拟机 TCP 服务

在 Linux 客体启用 TCP 回环。一个入口直接入队，另一个通过持久 TCP 连接提交 4 B 请求编号及 32 B 激活；服务器常驻权重，两条路径使用同一工作队列和 PCIe 端点。网络返回全部 256 个整数及诊断字段。直接与回环在同一客体交替执行，各跑 12 次。随后让独立的客户端与服务端 Linux 客体使用两块 e1000 虚拟网卡经隔离链路连接，再发 12 次相同请求。只有服务端持有 PCIe 设备。

## 运行

从仓库根目录执行 `make lab22`。同实验 21。复用同一内核、驱动、权重和虚拟设备。 [环境与完整复现顺序](../../docs/EXPERIMENTS_09_23.md#复现环境)

## 交付与验收

按编号核对响应，客户端逐字节检查三种路径的输出，每次均应观察到 64 条设备命令。分别记录排队、拷贝、设备和客户端往返；每条路径去掉首次后取 11 次中位数。

见下方本次计时。回环和跨机结果包含序列化与 Linux 协议栈开销，跨机还经过两块仿真网卡；客体单调钟受 TCG 与宿主调度影响。
