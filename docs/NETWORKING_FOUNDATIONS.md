# 网络与分布式通信：从 Socket 到远程 AI 服务

更新：2026-11-17。NET01–NET06 为本项目原创模块编号，全部为待实现的实验设计。课程把 CSAPP 网络/并发、OSTEP 同步与恢复、算法队列及 ENG04 可靠性接入远程推理和 Agent；不以完成分布式训练或生产集群为目标。

## 定位与前置条件

网络连接机器之间的服务；[PCIe](PCIE_IO_FOUNDATIONS.md) 连接主机与设备；[CXL](CXL_MEMORY_FOUNDATIONS.md) 扩展内存与一致性相关知识。三者可共同组成系统，不是互相替换的接口。

从 C/Python、进程与 Socket 起步。NET01–NET03 可使用回环接口或两个独立 Linux guest，不依赖 NPU、完整 LFS 或 PCIe。远程 NPU 推理需额外通过本地运行时和驱动验收。总体安排为 [S2 网络并行路线](ROADMAP.md)。

## 知识与实验

| 模块 | 知识范围 | 原创实验与产物 | 验收门槛 |
| --- | --- | --- | --- |
| NET01 网络路径 | Ethernet 帧、MAC/IP、ARP/IPv6 邻居发现、子网、路由、DNS；UDP 与 TCP 的用途 | 画出双 guest 拓扑，记录地址、路由和一次请求的分层抓包 | 能区分链路、地址、解析和端口故障；地址与抓包对应，记录抓包位置 |
| NET02 Socket 与消息 | TCP 字节流、连接生命周期、部分读写、字节序、消息长度、UDP 丢失/乱序 | 实现带长度和版本字段的有界请求/响应协议；注入拆分、合并、截断与超长输入 | 不假定一次读取等于一个请求；拒绝非法长度，断连可回收资源；UDP 实验单独记录结果 |
| NET03 AI 服务 | HTTP/RPC、序列化、模型版本、deadline、取消、请求编号 | CPU 确定性 GEMM 服务 → 小模型推理服务；输出协议与服务契约 | 本地与远程相同输入结果一致；固定生成参数；服务端区分校验失败、超时和计算错误 |
| NET04 并发与可靠性 | 有界队列、背压、连接池、重试退避、幂等、持久状态；HTTP/TLS 与身份认证 | 两 guest 的客户端/服务端，注入慢请求、断连、重启和重复请求；建立负载报告 | 队列满时明确拒绝；重试次数有界；对模拟副作用验证去重与恢复，未解决的崩溃窗口须记录 |
| NET05 Agent 与设备接入 | 远程工具边界、推理后端选择、数据传输与计算开销 | Agent → RPC → CPU/NPU 运行时；记录请求编号、模型版本和后端轨迹 | CPU 路径先通过；NPU 路径需真实调用证据及数值对照；端到端失败不可伪装成功 |
| NET06 高性能通信进阶 | NIC 描述符队列、DMA、零拷贝边界、RDMA/RoCE、内存注册、完成队列；集合通信概念 | 先用延迟/带宽模型比较发送粒度；条件具备后单独复现 RDMA 基础传输 | 理论估算、软件实现和硬件测量分栏；记录注册/同步/传输成本，不据此宣称分布式训练完成 |

NET04 的 TLS、认证使用维护中的标准库；实验网络先隔离，建立访问控制后才扩大可访问范围。重试不自动提供“恰好一次”执行；带副作用工具必须定义请求编号的作用域、去重保留时间、事务边界和不确定结果的查询方式。取消请求也不保证已经开始的设备操作立即停止。

## 首个贯通实验：双节点 CPU 推理服务

1. 固定 QEMU、guest 内核/rootfs 与虚拟网卡配置，保存拓扑。先验证单机回环协议，再连接两个 guest；不要求先构建 LFS。
2. 节点 A 发送固定形状的整数矩阵；节点 B 调用 CPU 参考实现。协议校验形状、类型、数据长度和总资源上限，网络消息不携带可直接解引用的指针。
3. 对照本地参考结果，覆盖空消息、截断消息、重复编号、超时和服务重启；随后把同一协议框架扩展为有版本的模型推理接口。
4. 分别测量客户端总耗时、服务端排队/计算耗时、字节数、吞吐量与 P50/P95/P99。跨机器单向时延需要时钟同步；首版采用客户端单调时钟测往返时间。
5. 完成本地 NPU 后端后开展 NET05，保持输入、模型、生成配置与负载一致；分别报告首 token 延迟、输出速率和 Agent 任务成功率。

## 环境与开放资料

QEMU 的虚拟网卡与网络后端可连接 guest、宿主网络或其他 QEMU 实例；后端和权限要求因宿主平台不同。本机 macOS 的第一步优先评估用户态网络/端口转发或 guest 间后端，Linux TAP/netns 的命令另在 Linux 实验环境验证。[QEMU 网络文档](https://www.qemu.org/docs/master/system/devices/net.html)

- HTTP 方法、状态与幂等语义：[RFC 9110](https://www.rfc-editor.org/rfc/rfc9110.html)。
- RDMA 用户态组件与示例参考：[linux-rdma/rdma-core](https://github.com/linux-rdma/rdma-core)；NET06 为可选进阶，具体软 RDMA/硬件支持另验。
