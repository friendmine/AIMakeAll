# 课程目录

面向愿意从基础开始学习的开发者。先掌握 Python 基本语法、C 指针和数组、二进制补码、矩阵乘法；不要求先会芯片设计。除实验 00 外，下表是待逐章编写并实现的课程，不是已完成的实验列表。

## 贯穿课程的系统基础

新增 [CSAPP 全书基础模块 CS01–CS12](CSAPP_FOUNDATIONS.md)，与下方 AI 单元 00–16 并行，保持编号独立。按第三版 12 章覆盖：系统概览、信息表示、机器级程序、处理器、性能优化、存储层次、链接、异常控制流、虚拟内存、系统 I/O、网络、并发；错误处理贯穿全部实验。

每个模块都有知识点、项目实验与验收标准。目前完成知识映射和计划，实验待实现；先学 CS01/CS02，再按硬件、运行时、模型、Agent 的需要进入后续模块。整体依赖见 [全景图](PROJECT_MAP.md)。

## AI 主线单元

| 单元 | 核心概念 | 动手内容 | 验收证据 |
| --- | --- | --- | --- |
| 00 | INT8、INT32、点积、MAC | [运行参考实现与 MAC](../labs/00-int8-matmul/README.md) | 固定结果、边界测试、RTL PASS |
| 01 | 组合/时序逻辑、复位、握手 | 寄存器与有符号乘加 | 波形解释和溢出行为 |
| 02 | ISA、ABI、链接脚本、MMIO | RISC-V 裸机 Hello World | 编译命令、反汇编、串口输出 |
| 03 | 存储层次、tiling、复用 | 4×4 MAC 阵列与尾块 | 随机输入逐元素一致 |
| 04 | 总线、DMA、中断、内存屏障 | CPU + NPU SoC | 驱动结果、异常测试 |
| 05 | QEMU 系统模拟与机器模型 | 固定板级运行环境 | 可复现 guest 启动 |
| 06 | MMIO 回调、guest RAM、安全边界 | 自定义 NPU 设备 | qtest 与 guest 集成测试 |
| 07 | 运行时、算子分派、基准 | C 参考与设备后端 | 正确性与多路径耗时 |
| 08 | tokenizer、数据切分、交叉熵 | byte tokenizer 与 bigram | 数据来源、验证损失 |
| 09 | 反向传播、注意力、因果掩码 | 自写 Transformer | 掩码测试、梯度检查 |
| 10 | 优化器、训练稳定性、过拟合 | 从随机权重训练 | 配置、曲线、独立验证 |
| 11 | 自回归生成、KV cache | CPU 推理 | cache 开关结果对照 |
| 12 | 对称量化、缩放、误差 | INT8 权重导出 | logits 与困惑度对照 |
| 13 | 算子映射、带宽瓶颈 | NPU 跑模型线性层 | prefill/decode 分开评测 |
| 14 | 工具协议、状态、上下文 | Agent 循环和工具注册 | 合法与非法调用测试 |
| 15 | 工具训练、任务评估、终止 | 小模型工具调用训练 | 独立任务成功率 |
| 16 | 全链路调试与性能分析 | Agent → LLM → NPU | 可复现端到端报告 |

每章统一写作模板：学习目标 → 前置知识 → 原理推导 → 文件与接口 → 运行命令 → 预期结果 → 常见错误 → 扩展练习 → 原始来源。命令必须实际运行后才能标记“已验证”。

学习顺序按表递进；模型基础单元 08–11 可在完成实验 00 后提前学习，等硬件接口稳定再做单元 12–13 的集成。
