# 课程目录

面向愿意从基础开始学习的开发者。先掌握 Python 基本语法、C 指针和数组、二进制补码、矩阵乘法；不要求先会芯片设计。除实验 00 外，下表是待逐章编写并实现的课程，不是已完成的实验列表。

课程统一采用 [仿真优先与数字电路交付原则](SIMULATION_FIRST.md)：硬件实验做 RTL/波形/综合，系统实验做 QEMU/Linux/虚拟网络。板卡、PHY 电气验证和流片不列入核心验收。网络补 NET-H1–H3 数字数据路径，PCIe IO06 改为事务级/RTL 仿真，CXL 补 CX-H1/H2 子模块与一致性模型，均待实现。

## 贯穿课程的系统基础

新增 [CSAPP 全书基础模块 CS01–CS12](CSAPP_FOUNDATIONS.md)，与下方 AI 单元 00–16 并行，保持编号独立。按第三版 12 章覆盖：系统概览、信息表示、机器级程序、处理器、性能优化、存储层次、链接、异常控制流、虚拟内存、系统 I/O、网络、并发；错误处理贯穿全部实验。

每个模块都有知识点、项目实验与验收标准。目前完成知识映射和计划，实验待实现；先学 CS01/CS02，再按硬件、运行时、模型、Agent 的需要进入后续模块。整体依赖见 [全景图](PROJECT_MAP.md)。

## 贯穿课程的深度学习基础

[Understanding Deep Learning 模块 UDL01–UDL21](UDL_FOUNDATIONS.md) 覆盖模型表达、损失与优化、反向传播、泛化、网络结构、生成模型、强化学习、理论与伦理；附录 UDL-A/B/C 补符号、数学和概率。各模块都有项目实验与验收设计，当前实验待实现。

LLM 优先路线为数学按需补齐 → UDL01–UDL09 → UDL11/UDL12 → 自写 Transformer 与 MiniMind → 项目量化部署专项。UDL08/UDL21 贯穿评估，UDL19 用于后续 Agent RL；CNN、GNN 和生成模型保留为扩展实验，不阻塞首版四阶段闭环。

[工程专项 ENG01–ENG04](ENGINEERING_BRIDGES.md) 将遗漏的连接要求编成实验：ENG01 数值与量化对应单元 00、12–13；ENG02 数据与训练对应 08–10、15；ENG03 性能和系统验证贯穿 01–07、13、16；ENG04 检索与可靠性对应 14–16。每项都要求可复现产物和失败/边界用例。

学习顺序按表递进；模型基础单元 08–11 可在完成实验 00 后提前学习，等硬件接口稳定再做单元 12–13 的集成。

## 操作系统构建基础与 LFS 扩展

[Linux From Scratch 模块 LFS01–LFS11](LFS_FOUNDATIONS.md) 以 13.1-systemd 版为基准：构建环境 → 源码与依赖 → 工具链自举 → 临时用户态与 chroot → 基础系统 → 内核和启动 → 维护，并包含前言与附录 A–D 的学习用途。

结合 CS03/CS07 理解工具链，CS08–CS10 理解启动、内存与文件系统，CS10–CS12 理解推理服务。先在独立 Linux 环境复现基础流程，再将方法迁移到 RV64 Linux/QEMU；这属于单元 05–07、11–16 的扩展。当前完成知识和实验规划，未建立 LFS 环境或镜像。

## MiniMind 阅读与复现参考

先以 [Build a Large Language Model (From Scratch) 的七章与附录映射](../models/README.md) 细化单元 08–15：文本与标签 → 注意力 → GPT 组装 → 随机初始化预训练 → 指令微调；分类微调与 LoRA 为分支。UDL 提供原理，本书提供逐步实现路线，MiniMind 提供完整工程对照。LLMFS01–07 与附录条目均为待实现计划，归入现有领域 10，不新增一级课程或目录。
