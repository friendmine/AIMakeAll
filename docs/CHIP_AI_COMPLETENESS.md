# 芯片与 AI 全景课程补全

更新：2026-11-18。目标是让一个人建立芯片与 AI 的全景认知，能独立完成有边界的跨层系统，并选择少数方向深入。全景理解、教学实现、工业产品能力分别验收，不以阅读完目录代表掌握全部专业。

本轮只完成课程、实验规划和知识覆盖图。既有十条路线的 30 个验收节点，六项跨层补强的 18 个节点，以及新增 RT/MM/CAUSE 的 9 个节点和 DESIGN 综合实验的 4 个检查点，全部待实现或待验证；PRA、DEP、DLE 复用并细化既有实验，不与原十组 60 项深化实验简单相加。状态统一由 [课程状态总表](CURRICULUM.md#课程状态总表) 维护。保持十八个知识领域编号与一级目录不变，详细章节和实验资产后续放入已有 `docs/`、`labs/`、`reference/`、`hardware/`、`models/`、`tests/` 等目录。

## SIG 数学与信号系统

前置：微分积分、复数、矩阵、概率和 Python；先做 MATH 的线代/数值内容。课程依次为：① 一阶/二阶常微分方程、初值、量纲与数值积分；② 连续/离散信号、线性时不变系统、冲激响应和卷积；③ Fourier、Laplace、Z 变换、频率响应、采样与混叠；④ 状态空间、极点、稳定性和反馈。偏微分方程与半导体输运只做认知入口，器件深入再学。

| 节点 | 实验步骤与交付物 | 验收标准 |
| --- | --- | --- |
| SIG-1 | 推导 RC 阶跃解析解；取 R=1 kΩ、C=1 μF、输入 1 V、初值 0，比较 Euler 与 RK4，扫描步长，交付单位表、方程、误差曲线 | 在 0–5τ、步长 τ/100 下，Euler 最大绝对误差 <0.005 V，RK4 <0.000001 V；减半步长误差下降；大步长反例解释稳定性，不能只展示平滑曲线 |
| SIG-2 | 用采样率 1 kHz 生成 100 Hz 与 700 Hz 正弦，分析频谱、混叠与 FIR 低通；交付直接卷积和频域对照 | 解释 700 Hz 的 300 Hz 混叠及相位关系；频域卷积零填充避免循环混叠，双精度两路径误差 ≤1e-9；更换采样率后预测并复核频点 |
| SIG-3 | 对质量-弹簧-阻尼模型建立二阶方程和状态空间，离散化并加入反馈；交付稳定/不稳定参数组、步长收敛与极点报告 | 无输入无阻尼时用能量误差随步长收敛核验；阻尼案例与解析/高精度参考对照；区分物理不稳定和积分数值不稳定，给 EMB 保留模型契约 |

默认使用数值仿真，无 ADC/DAC 板卡要求。学习入口：[MIT 6.003 Signals and Systems](https://ocw.mit.edu/courses/6-003-signals-and-systems-fall-2011/)。上述参数和验收线为本项目教学设计，尚无实测结果。

## CIR 电路与半导体器件

课程依次为：① 电压/电流/功率、KCL/KVL、节点法、戴维南等效、RLC 暂态与交流小信号；② 能带、载流子、掺杂、PN 结、MOS 电容与 MOSFET 工作区、I-V 和电容模型；③ CMOS 反相器、NAND/NOR、传输门、锁存器到 SRAM；④ 负载、扇出、RC 寄生、PVT、噪声容限、热噪声与串扰。先用教学模型理解趋势，再对照锁定的开放 PDK 模型；不以长沟道平方律预测先进工艺性能。

| 节点 | 实验步骤与交付物 | 验收标准 |
| --- | --- | --- |
| CIR-1 | 手算并用 SPICE 检查 1 kΩ/1 kΩ 分压与 SIG-1 RC；交付网表、工作点/暂态结果和 KCL 残差 | 1 V 输入分压为 0.5 V，绝对误差 ≤1e-6 V；同初值 RC 与解析解最大误差 <0.001 V，记录积分/容差；断路、短路和无地参考给出预期错误 |
| CIR-2 | 扫描 NMOS/PMOS I-V，再搭 CMOS 反相器与 NAND；交付工作区解释、VTC、真值表、传播延时与输入 slew/负载表 | DC 高低电平按所选库的阈值或预先声明的教学阈值判定；VIH/VIL 从 VTC 斜率与适用条件提取；每个真值组合通过，延时测量说明输入/输出交点 |
| CIR-3 | 在同一反相器/短互连加入受控寄生与耦合，扫电压温度和模型提供的工艺角；交付无/有寄生对照、噪声容限、负载延时与噪声谱报告 | 记录模型/网表/单位/有效范围；解释最差角和串扰；小信号噪声谱与时域注入分别报告，无随机失配模型时不得将 PVT 扫描称为良率预测 |

器件与电气部分交付方程、网表和 SPICE 证据，不要求综合为 RTL。数字门级行为再与 DD/ARITH 接通；SRAM 读写裕量、模拟放大器/PLL/ADC 为后续深入，不阻塞 NPU。

参考：[MIT 6.002](https://ocw.mit.edu/courses/6-002-circuits-and-electronics-spring-2007/)、[MIT 6.012](https://ocw.mit.edu/courses/6-012-microelectronic-devices-and-circuits-fall-2009/)、[ngspice 文档](https://ngspice.sourceforge.io/docs.html)、[SKY130 PDK 文档](https://skywater-pdk.readthedocs.io/en/main/)。工具和模型在首次实施时锁版，阅读入口不代表本机兼容性已验。

## PRA 数字设计实践贯通

本路线落实 [DD/DV/SIM](CURRICULUM.md) 已有计划，不另起一套 RTL 规格。顺序是读懂契约 → 独立参考与时序图 → RTL 与测试台 → 定向/随机调试 → 综合与回归 → 系统接入。每个节点保留一次失败、定位、修复、回归记录；只运行无报错不足以证明调试能力。

| 节点 | 实验步骤与交付物 | 验收标准 |
| --- | --- | --- |
| PRA-1 | 实现 DD03 的 4 深度、8 位同步 FIFO，独立队列评分器、波形和综合脚本，关联 DV/SIM 对应条目 | 沿前握手，空无直通，满不接受同沿写；高有效同步复位取消数据；覆盖回绕、同读写、背压和非空复位，源在背压时保持数据；队列顺序/占用逐拍一致，综合无未解析模块与非预期锁存 |
| PRA-2 | 在隔离练习副本引入计数边界、复位、握手三类错误；交付触发向量、最早分歧、修复与回归报告 | 每类错误至少被一个对应检查捕获；恢复正确实现后全部通过；未触发记覆盖缺口。形式证明若开展，列出深度/假设，不能用仿真 PASS 替代证明 |
| PRA-3 | 将已验 FIFO/算术模块接入小数据通路，再按 M1 做 4×4 阵列与尾块；交付参考、RTL、综合、事务与周期报告 | 固定/随机/负值/尾块与 Python/C 一致；改变流水线延迟仍按事务匹配；复位/忙/错误回归通过。无目标库仅报告通用综合统计，不给出芯片 MHz；CPU 发起 GEMM 另按 M1 验收 |

PRA-1/2 对应 G1，PRA-3 按 M1/G2 分步完成。已有单 MAC 的异步低有效复位不随 FIFO 的同步复位合同改变。

## HET CPU GPU DSP 对照

课程依次为：① 顺序流水线、冒险、预测、超标量、乱序、寄存器重命名与精确异常；② GPU SIMT、warp/wave、分歧、访存合并、共享存储和占用约束；③ DSP 的 FIR/FFT、循环缓冲、定点饱和、SIMD/VLIW；④ CPU/GPU/DSP/NPU 的控制、数据复用、可编程性与带宽权衡。GPU 术语随所选架构注明，教学分组宽度不冒充所有 GPU 的固定参数。

| 节点 | 实验步骤与交付物 | 验收标准 |
| --- | --- | --- |
| HET-1 | 在有限整数指令轨迹上比较顺序与简化乱序模型，含依赖、预测错误、重命名与提交；交付最终状态及等待原因账本 | 两模型与顺序 ISA 参考的提交结果一致；错误路径无架构可见写入；声明队列容量/端口/内存延迟并扫描，解释 IPC 与停顿；不能据教学模型声称完成高性能 CPU |
| HET-2 | 用自写 SIMT 事务模型运行连续/跨步访存和分支核，比较 8/32 条教学 lane，交付活跃掩码、访存事务和 barrier 轨迹 | 每个输出与标量参考一致；人为分歧/非合并场景能改变账本；不合法同步被拒绝或报告；不要求 CUDA 安装，真实 GPU 测速为独立选修 |
| HET-3 | 对相同 FIR、点积、GEMM 列出 CPU/DSP/NPU 数据流；FIR 用浮点及 Q15 参考，再选择直接型或转置型 RTL | 量化、累加位宽、舍入/饱和先写合同；整数/RTL 对照按合同通过，冲激与正弦输入检查响应；以统一运算/访存计数比较，RTL 周期、宿主耗时和模型估算分列 |

接口仍由 [ARCH/MEM](ARCHITECTURE.md)、[ARITH/PPA](DIGITAL_DESIGN_TIMING.md) 管理。HET 的饱和 DSP 不改变 NPU v0 的 INT32 回绕。CPU 参考：[MIT 6.823](https://ocw.mit.edu/courses/6-823-computer-system-architecture-fall-2005/)。GPU 概念对照 [NVIDIA SIMT 官方说明](https://docs.nvidia.com/cuda/cuda-programming-guide/03-advanced/advanced-kernel-programming.html)，CUDA 仅作阅读参考；实际实验优先原创开放教学模型。

## CHIP 物理实现与产品流程

课程依次为：① 晶圆、氧化/沉积/光刻/刻蚀/掺杂/互连的认知链，工艺角、PDK 与设计规则；② 标准单元、Liberty/LEF、宏、综合、约束、布局、时钟树、布线、RC 提取、STA、DRC/LVS；③ 电源网、IR drop、EM、功耗、热与封装 RLC/散热模型；④ DFT/scan/存储测试、晶圆测试、封装测试、binning、缺陷/参数良率、可靠性与现场故障。制造/量产环节提供模型和流程认知，不承诺由开放 PDK 实现工业签核。

| 节点 | 实验步骤与交付物 | 验收标准 |
| --- | --- | --- |
| CHIP-1 | 选已通过 PRA 的小模块，锁定开放工艺与库，沿综合到布局布线流程；交付网表、约束、布局、寄生、STA/DRC/LVS 及问题清单 | 前后功能对照通过；报告完整输入约束、未约束路径和检查覆盖；选定角下 setup/hold 与所用规则检查达标，未提供的检查标未验证；不得只凭 GDS 文件存在记成功 |
| CHIP-2 | 在同一布局上建立 PDN/活动功耗模型，另用集总封装 RLC 和热 RC 做阶跃负载；交付电压降/温升/时序敏感性 | 输入电流、功率、边界温度及封装参数可追溯；网格/步长加密结果收敛；违反预定电压/温度预算能被检测；EM 缺少适用规则时仅作认知，不出可靠性签核结论 |
| CHIP-3 | 在小电路上插入教学 scan、枚举 stuck-at 故障并生成测试；为小 RAM 设计 March 测试；另扫假设面积/缺陷密度的 Poisson 良率模型 | 报告可检测、不可检测、未覆盖故障，分母明确；scan 正常模式功能不变；RAM 故障模型逐项说明；Y=exp(-A·D0) 量纲正确、0≤Y≤1，参数标假设，不能称实际制造良率 |

本路线连接 PPA 与 RAS：DFT 生产测试、运行时 ECC 和软件故障恢复各有对象，互不替代。封装/供电/测试均采用电脑内模型；不要求采购或流片。参考：[OpenROAD 流程与工具](https://openroad.readthedocs.io/en/latest/main/README.html)、[SKY130](https://skywater-pdk.readthedocs.io/en/main/)。制造、封装与良率实验的简化假设随报告保存。

## DEP 编译运行时设备贯通

课程依次为：① 单 Linear 的 FP32 数学、形状/布局/量化合同；② 有限 IR、K 分块、内存生命周期与版本化执行计划；③ C 解释器、CPU 后端、MMIO guest 驱动与 QEMU 设备；④ 同向量 RTL 对照、模型部署与错误归因。复用 [AC01–AC12](AI_COMPILATION.md) 和 G2，不扩展为通用编译器或新增 NPU 指令。

| 节点 | 实验步骤与交付物 | 验收标准 |
| --- | --- | --- |
| DEP-1 | 固定 M=5、K=257、N=7，X 与 W[N,K] + bias；转换为 B[K,N]，按约定 scale 量化，导出 K=256/1 两个任务及缓冲区账本 | 每任务独立清零 INT32 累加，CPU 合并后只做一次约定缩放/偏置；量化参数跨 K 分块一致；Python 整数参考与计划解释器逐元素一致，FP32/量化误差单独报告 |
| DEP-2 | 同一包接 C CPU 与 guest/QEMU 后端，加入布局错误、坏版本、越界、超时；交付模型包、轨迹、失败与回收报告 | 支持路径结果与独立整数参考一致；包验证先于执行；v0 非法请求按规范处理且不改 C；busy/reset/clear/错误语义一致；版本/能力不足明确拒绝或记录 CPU 回退，不静默假成功 |
| DEP-3 | 使用相同整数任务对照 RTL，再接训练模型至少一个线性层，最后逐层扩大；交付误差定位、prefill/decode、搬运和回退报告 | 每层首个数值分歧可定位；模型质量门槛沿用 M3；QEMU 耗时、RTL 周期、宿主基线分列，未满足精度/负载可比条件不报加速比；完整 LLM/Agent 另验 |

先 CPU，再 guest/QEMU，再 RTL 离线差分，最后模型；不要求实时联仿。小矩阵仅证明路径，不能证明真实 NPU 性能。设备限制以 [NPU v0](../specs/npu-v0.md) 为唯一依据，教学计划不能隐含引入缓存一致性、ECC 或新错误码。

## CLA 传统机器学习与经典 AI

课程依次为：① 线性/逻辑回归、kNN、朴素贝叶斯、决策树与集成；② SVM/核方法、PCA、k-means、密度聚类和混合模型；③ 状态空间搜索、CSP、知识表示、命题/一阶逻辑、蕴含与规则推理；④ 贝叶斯网络、精确/采样推断、HMM、MDP，以及前置条件/效果形式的经典规划。把预测、推断和规划分开，再连接 Agent 的工具选择。

| 节点 | 实验步骤与交付物 | 验收标准 |
| --- | --- | --- |
| CLA-1 | 在原创线性可分、异或/同心圆、含噪表格三类数据上比较线性模型、树/随机森林、RBF SVM；另对无标签簇比较 k-means/密度聚类 | 固定训练/验证/测试划分，预处理仅拟合训练集；超参数只看验证集；至少 3 个种子报告质量/耗时/模型大小；聚类标签置换不影响评价，不用测试标签训练；不要求某模型必胜 |
| CLA-2 | 为受限工具定义有限命题、动作前置/效果与目标，手写小规划器，另用真值表校验逻辑蕴含和 CSP 解 | 可解任务动作全部合法、终态达标；小状态空间与穷举最短路径对照；无解/矛盾有明确结果；注明闭世界与有限域，一阶逻辑仅做有限实例化，不称通用定理证明器 |
| CLA-3 | 对小贝叶斯网络做枚举与变量消元，对离散 HMM 做 filtering；用相同证据驱动工具决策对照 | 概率归一化、两种精确推断误差 ≤1e-10，零概率证据明确处理；HMM 与短序列穷举对照；部分可观测决策不能当全知规划，采样误差独立记录 |

参考：[scikit-learn 监督学习](https://scikit-learn.org/stable/supervised_learning.html)、[聚类](https://scikit-learn.org/stable/modules/clustering.html)、[Berkeley CS188](https://inst.eecs.berkeley.edu/~cs188/textbook/)、[AIMA 作者目录](https://aima.cs.berkeley.edu/)。AIMA 是知识导航，原创小实验不以购买或复制书稿为前提。CLA 与 AGQ 共用任务划分，但经典规划成绩不冒充自训练模型能力。

## DLE 深度学习推导与比较

已有 UDL 章节地图转为“推导 → 小实现 → 独立校验 → 公平比较 → 迁移/排错”。课程依次为：① 链式法则、稳定损失与优化；② MLP/CNN/残差/注意力/GNN 的归纳偏置与对称性；③ 自回归、VAE、flow、GAN、diffusion 的目标和采样；④ 泛化、校准、消融、预算与模型卡。生成模型先在可视化低维数据上比较，LLM 继续沿 LLMs From Scratch 和 MiniMind 主线。

| 节点 | 实验步骤与交付物 | 验收标准 |
| --- | --- | --- |
| DLE-1 | 对平滑激活小 MLP 手推损失/梯度，手写反传，再与中心差分及自动求导比较；交付公式、维度表、梯度和训练记录 | float64 小输入上 max_abs_error / max(1,max_abs_reference) ≤1e-6；有限差分步长扫描支持结论；非光滑点单列；先能过拟合固定小样本，再检查独立验证集，不以过拟合证明泛化 |
| DLE-2 | 复用 UDL10/12/13：卷积与展开 GEMM、注意力因果掩码、GNN 重编号；同一小任务选择 MLP/CNN/Transformer 中适合的两种比较 | 算子对照给定容差通过，改变未来 token 不影响过去输出，图重编号结果对应重排；同划分/调参预算，报告参数与计算差异，至少 3 种子；不跨不同任务给模型排名 |
| DLE-3 | 复用 UDL14–18，在同一二维混合分布训练小 VAE、flow、GAN、diffusion；交付目标推导、样本、分布覆盖和成本表 | 用留出数据及同一套分布指标比较，训练/采样预算分别记录；仅对有可比较密度的模型报相应似然，不将 ELBO/GAN loss/扩散 loss 直接排序；保留模式丢失等失败样例 |

UDL 原有章节与项目实验关系见 [UDL](UDL_FOUNDATIONS.md)，LLM 七章映射见 [模型路线](../models/README.md)。DLE-1/2 为主线基础与选定结构验收；DLE-3 为分轮专题，不让四种生成模型阻塞小 LLM。各节点仍需独立学习者完成解释、迁移与排错任务。

## EMB 感知控制与具身

前置为 SIG 状态空间/采样、CLA 概率推断、DLE 基础。课程依次为：① 相机/图像几何、卷积特征、光照与噪声，音频采样、STFT/频谱特征与小分类器；② 时间戳、坐标系、传感误差/标定、观测模型；③ Kalman/EKF、可观测性、状态估计，PID/LQR、稳定性与饱和；④ 运动学/动力学、规划、闭环控制、RL 与安全约束。先可观测的简单对象，再部分观测；学习控制与物理执行速度匹配，不把文本 Agent 循环当实时控制器。

| 节点 | 实验步骤与交付物 | 验收标准 |
| --- | --- | --- |
| EMB-1 | 自生成小图像和音调/短音序列，实现图像目标位置提取、STFT 特征与分类；交付数据生成器、噪声/采样配置、误差和混淆矩阵 | 按场景/序列划分，噪声扰动后报告性能变化；坐标/时间/单位一致，静音/遮挡有明确无效观测；音调识别仅为语音前置，不能称已完成语音识别 |
| EMB-2 | 线性运动对象用 Kalman filter 融合带噪位置/速度，再接 PID 或 LQR；交付真值、观测、估计、控制轨迹 | 在预先固定的至少 20 个种子上，与原始观测/无反馈基线比较 RMSE、超调/稳定时间和控制能量；零噪声解析用例通过；发散、丢样、延迟和执行器饱和被记录，不靠挑选成功轨迹 |
| EMB-3 | 自写二维差速机器人/小车仿真，连接感知、估计、图搜索/经典规划与控制；学习策略作为可选对照 | 预先固定独立场景与成功/碰撞/超时定义，报告所有场景结果；任务循环仅使用传感观测，不泄漏真值；动作有界、终止和故障停车可测；改变步长检验收敛，不声称已验证真实机器人迁移 |

EMB-1 的专题延伸明确为：视觉从相机投影/标定进入小目标检测，交付重投影误差、定位误差与遮挡评估；语音从 STFT/声学特征进入少词命令识别，再做短序列 CTC 对齐/解码，交付说话者隔离的划分、混淆矩阵、CER/WER 和静音/噪声失败案例。短序列 CTC 概率先与路径穷举对照，实际语音数据必须单独核验授权；缺数据时标依赖未就绪，不用音调分类替代语音验收。核心交付用原创二维仿真，不依赖机器人、摄像头或麦克风。控制/动力学阅读入口：[MIT Underactuated Robotics](https://underactuated.mit.edu/)，高级内容按 SIG/线代前置逐步进入。

## SCALE 大规模 AI 工程

课程依次为：① 数据并行、collective、梯度聚合与全局 batch；② 张量/流水线并行、参数/优化器分片、激活重算与通信量；③ 多后端推理、批处理/KV 预算、排队/限流/取消；④ 生产服务的版本、指标/追踪、SLO、灰度/回滚、检查点恢复与故障演练。先单机多进程验证语义，再选择多设备实测；教学档不依赖集群。

| 节点 | 实验步骤与交付物 | 验收标准 |
| --- | --- | --- |
| SCALE-1 | 两个 CPU worker 训练小模型，比较单进程全局 batch；加入不等本地 batch 与断点恢复 | 聚合按有效样本数加权，等同一次全局更新；确定性 float64 小模型一步参数误差 ≤1e-8，使用无随机层的固定输入；保存模型/优化器/随机/采样位置，恢复轨迹在声明容差内一致；worker 失败不能默默丢数据记成功 |
| SCALE-2 | CPU 进程模拟张量分片/流水阶段，部署两条推理后端，记录消息、分片与 KV 账本；多 GPU 为可选复现档 | 分片合成输出与单进程参考一致；请求/序列/版本匹配，乱序/延迟/故障能检测；容量不足明确拒绝或排队；报告通信量和关键路径，虚拟节点数不当实际设备数或 GPU 加速证据 |
| SCALE-3 | 在本地隔离服务做固定到达负载、限流、取消、超时、重启和版本回滚；交付部署清单、指标原始记录及故障演练报告 | 运行前声明负载/资源上限/SLO；报告成功/错误/拒绝率、吞吐和 p50/p95/p99（样本不足注明）；队列有界、请求完成或终止可追踪、旧新版本隔离；副作用恢复遵循 STATE，不宣称跨服务天然 exactly-once |

参考：[PyTorch 分布式教程](https://docs.pytorch.org/tutorials/distributed.html)。实际后端、操作系统和版本兼容性实施时核验；CPU 路线可先手写消息与参数聚合。NET/S2 提供通信，PERF 提供公平测量，STATE/SW 提供恢复和正确性；CXL 不作为分布式训练前置。生产级多机可用性、真实 GPU/NIC 性能仍需独立环境证据。

### LIFE SoC 完整运行生命周期

课程连接电源有效、时钟稳定、复位域/释放、Boot ROM、固件与外设初始化、运行/静止、休眠唤醒、看门狗和调试观察。先建立单时钟离散事件模型，电源/时钟就绪使用测试输入；后续才引入真实时钟门控、多时钟、隔离/保持及 DVFS。数字仿真不模拟真实电压下降或亚稳态。

| 节点 | 实验步骤与交付物 | 验收标准 |
| --- | --- | --- |
| LIFE-1 上电到运行 | 定义 OFF/WAIT_POWER/WAIT_CLOCK/RESET/BOOT/RUN/FAULT 状态和允许访问表；用教学控制 RTL 与独立事件模型重放就绪/超时轨迹。交付状态图、复位/启动顺序、逐事件日志、断言、波形及综合结果 | RUN 前禁止任务派发；只有所需就绪条件满足且复位按约定释放才进入 BOOT；超时界限 T 的 T−1/T/T+1 用例有确定结果；中途复位产生新 epoch，旧响应不能使新任务成功；每条状态转移和禁止转移有测试 |
| LIFE-2 静止到唤醒 | 在外部平台管理包装中实现停止接单、排空或显式取消、保存约定状态、睡眠、唤醒和重新初始化；交付在途请求账本、保持/丢失状态表、时序图及恢复报告 | 忙时不能直接进入睡眠并丢失请求；每个已接收任务最终完成或明确取消，不能重复完成；在各过渡点注入复位/唤醒后符合状态表。保留 NPU v0 reset 清寄存器与取消任务语义，不隐含设备状态保持或新寄存器 |
| LIFE-3 恢复与可观测性 | 注入时钟未就绪、固件停在初始化、运行中设备无响应，增加有界看门狗与恢复次数；先模拟，M1/M2 就绪后接 guest。交付原因码、PC/状态/请求 ID 轨迹、失败到恢复的调试记录 | 每类故障可定位到启动/软件/设备层；计时和重试上限预先固定，超限进入明确失败态；恢复后的正常任务与基线一致；调试入口受 TRUST 权限约束。模型通过、RTL 通过和 guest 通过分列，日志不冒充已实现 JTAG 硬件 |

LIFE-1 的控制 RTL 不直接用普通逻辑与时钟相与。LIFE-2 初版用逻辑使能/事件暂停表达低功耗；真实门控单元、供电隔离、复位跨域和 PPA 另按 DD/PPA 证据验收。参考 [OpenTitan 电源管理](https://opentitan.org/book/hw/top_earlgrey/ip_autogen/pwrmgr/doc/theory_of_operation.html)，仅借鉴职责与顺序，不声称本项目已实现 OpenTitan。

### TRUST 硬件到模型的信任链

课程依次解释随机错误与主动篡改、哈希与签名、信任根/授权密钥、启动链、包认证与能力约束、防回滚、更新恢复、调试与工具权限。ECC/CRC 可检测特定错误但不证明来源；签名证明认证关系但不证明模型回答正确。侧信道、物理故障攻击与真实 OTP/熔丝只作边界认知，不纳入首批攻击实验。

| 节点 | 实验步骤与交付物 | 验收标准 |
| --- | --- | --- |
| TRUST-1 威胁与资产清单 | 画 ROM/固件/驱动/模型包/检索内容/工具的信任边界，固定一份小包的规范化清单、版本和哈希，使用标准签名实现生成教学签名。交付资产权限表、信任根来源、正反例包与验证日志 | 修改载荷、版本或能力字段后拒绝；未知签名者拒绝；“同时改数据与普通哈希”能展示未认证哈希的局限；允许密钥来自可信配置，不能由包自报公钥即获信任；临时测试私钥不入库，不自行设计密码算法 |
| TRUST-2 启动与模型认证 | 在模型中由固定信任根认证固件，再由授权加载器认证模型/执行计划；校验 ABI、长度、布局、允许算子、权限与最低安全版本。交付认证状态机、包格式合同和拒绝用例 | 合法授权包通过；坏签名、旧安全版本、错误 ABI、有效签名但越权的包在派发前拒绝，输出和设备不受影响；实际使用的字节与已验证字节一致，消除替换窗口；信任链模型与实际 QEMU 启动链分别验收 |
| TRUST-3 更新与恢复 | 用 A/B 槽、可信版本下限和撤销列表的教学状态模型，规定候选验证、试启动、确认与提交点；注入每个更新阶段的中断，并连接 Agent 工具策略。交付恢复表、授权审计和逐阶段重放 | 中断后只执行已认证且不低于版本下限的映像，或进入安全恢复；旧合法版本是否允许回退由预先策略决定；撤销密钥不能授权新加载；模型/检索文本不能提升工具或调试权限，正常更新和工具任务仍可完成 |

防回滚状态、信任根和撤销表在教学模型中假设攻击者不能任意修改；宿主普通文件不提供真实硬件抗回滚保证。认证后的包仍须经过 SW 的内存/格式校验。标准密码库候选在实施时核验平台、版本和许可；本轮无密钥、密码实现或设备 ABI 变更。参考 [OpenTitan 安全启动说明](https://opentitan.org/book/doc/security/specs/secure_boot/)。

### SHIFT 数据变化后的模型可靠性

课程连接输入分布变化、标签比例变化、条件关系变化、概率校准、选择性预测/拒答、可观测指标、延迟标签、更新与回滚。起点用可计算真分布的二维二分类数据，之后迁移到文本与 Agent；不以最大 softmax 概率直接证明答案可靠。

| 节点 | 实验步骤与交付物 | 验收标准 |
| --- | --- | --- |
| SHIFT-1 构造变化与失效 | 分别改变输入分布、类别先验或标签生成规则，冻结模型；交付生成器、变化前后真分布、准确率/Brier/NLL/可靠性图及至少三个种子的结果 | 训练、概率校准、阈值选择、最终留出数据按用途隔离；显式登记 P(x)、P(y)、P(y given x) 的变化与不变假设，类型可由生成参数复核；所有策略使用同一留出输入；保留输入分布不变但标签规则改变的反例，说明只看输入不能发现全部漂移 |
| SHIFT-2 校准与拒答 | 对固定模型做概率校准，在独立阈值集选拒答与告警阈值；加入轻量输入统计/延迟标签监测。交付覆盖率—错误率曲线、误报/漏报、触发延迟和分组报告 | 分箱、概率裁剪、空组及无接受样本处理预先固定；拒答同时报告覆盖率和全部任务成本，不将全拒答视为优质系统；阈值只由阈值集选定，最终测试不回流调参；未观测标签时不声称实时测得准确率 |
| SHIFT-3 更新与再验收 | 固定旧模型、新训练数据与候选版本，在模拟影子流量中比较后选择发布/回滚；将标签延迟、恢复与错误告警接 SCALE/STATE。交付版本化数据清单、指标、发布决策和回滚轨迹 | 更新数据不含最终测试标签；在预先锁定的原场景与变化场景留出集分别报告质量/覆盖/延迟；先声明可接受退化和资源上限，未达标不得发布；发布切换可追溯且请求只用一个明确版本；反复开发另留新测试集 |

监测到变化不等于识别根因，也不保证重新训练一定改善表现。初版验收要求计算、划分和处置正确，性能目标未达到必须保留失败；文本/LLM 的校准指标与分类指标另定义。概率校准参考 [scikit-learn 官方说明](https://scikit-learn.org/stable/modules/calibration.html)。

### SELECT 不同 AI 方法的统一比较

复用 CLA/AGQ 的原创有限工具世界：根据允许的事实、规则和任务目标，输出受限动作序列或明确拒绝；用确定性执行器判断目标与约束。规则策略、经典 ML、小神经网络、LLM、检索增强与规划器在同一输入/输出合同下比较，限定比较的任务范围。

| 节点 | 实验步骤与交付物 | 验收标准 |
| --- | --- | --- |
| SELECT-1 建立共同任务 | 固定结构化观察、等价文本表达、资料库、动作集合、预算、不可解情形及按模板/场景分组的划分。交付任务规范、独立执行器、手工可核对的期望和信息权限表 | 同一任务的策略得到相同允许事实；适配器只改变表示，不提供隐藏真值或答案；可解/不可解/非法动作样例可手工核对；成功以终态和约束判定，不强制同一动作序列；评估答案不进入资料库或训练集 |
| SELECT-2 建立多策略基线 | 先实现规则、树模型、小 MLP 和有限规划，再接检索加固定解析/执行策略及自训练 LLM；交付每种方法的训练/索引/推理配置与成本账本 | 使用同一留出任务和动作预算，报告成功、非法调用、拒答、超时、延迟与内存；训练/调参/索引成本分列，不以参数量相同代替公平；随机方法至少三个种子；尚缺 LLM 时只标其他基线通过，不补造模型成绩 |
| SELECT-3 消融与选择 | 分别改变规则、资料、噪声、任务长度和资源预算，做单因素消融；交付各方法失效边界、质量—成本表及一个新任务的选择说明 | 原始任务级结果和失败案例可追溯；检索开关、模型替换等比较保持其他条件明确；结论限于所测任务和预算；能说明何时规则/经典方法已经足够、何时需要检索/规划/学习，不能只给单个总排名 |

规划器的领域规则、规则系统的人工编码、LLM 的训练与检索索引都是前期投入，必须披露。检索本身不是完整决策器，须声明后接的决策方法；自训练与外部预训练模型如需对照分列。模型尚未实现时可以推进共同任务与确定性策略，不将规则成绩算作 LLM 能力。方法入口复用 CLA、DLE、AGQ 与 [CS188](https://inst.eecs.berkeley.edu/~cs188/textbook/)。

### LIMIT 理论边界与可证明范围

课程依次解释有限状态与一般程序、可判定性/停机问题、时间空间复杂度/归约、精确与启发式、有限样本学习界、形式性质/环境假设及经验结论。通识只需能判断结论类型；证明和学习理论细节按专题深入。

| 节点 | 实验步骤与交付物 | 验收标准 |
| --- | --- | --- |
| LIMIT-1 有界检查与无界命题 | 为小有限状态系统枚举可达状态，并为小解释器增加步数上限；复用 FIFO 占用不变量写归纳证明，构造在检查深度后才失败的例子。交付状态空间、证明前提、反例和结论分类表 | 全可达状态枚举仅对固定有限模型给完备结论；步数耗尽返回 UNKNOWN，不能当不终止证明；有界未发现反例不写成无界正确；FIFO 归纳步骤覆盖初始/保持，活性结论另列公平性与响应假设 |
| LIMIT-2 可行与高效 | 对最多 12 个变量的小 CNF 公式比较穷举与有预算启发式，递增规模并解释归约/最坏复杂度；交付解证书、搜索计数与资源曲线 | 候选赋值由独立求值器验证；只有完整搜索/有效证明才报 UNSAT，启发式超时为 UNKNOWN；小实例速度不推出一般多项式算法，无法从曲线宣称解决 P 与 NP；归约方向和适用问题必须说明 |
| LIMIT-3 学习与统计保证 | 在固定有限输入域和预先固定的有限假设集 H 上，枚举真风险，再抽取 iid 有界 0–1 损失样本计算经验风险；交付界的推导、重复试验、违反假设的反例 | 对非空固定 H、n≥1、0<δ<1，推导同时界 ε=sqrt(ln(2·abs(H)/δ)/(2n))，说明置信度 1−δ、H 预先固定、iid 和损失范围；ε>1 时解释界无信息；实验违界比例仅作演示，不替代概率证明；重复样本、用测试集选 H 或分布变化时不能原样套界 |

这里的学习界针对有限 H 和上述假设，不是任意神经网络或 Agent 的通用保证。停止问题不可判定的理论论证与有限程序实验分开；有限时间模拟也不能证明实物系统在所有环境中正确。参考 [MIT 6.045J 可计算性与复杂性](https://ocw.mit.edu/courses/6-045j-automata-computability-and-complexity-spring-2011/)；概率部分在 MATH-E5/E6 基础上推导 Hoeffding 界与有限集合 union bound。

### MIX 模拟与混合信号的系统角色

课程建立传感信号 → 放大与限幅 → 模拟抗混叠滤波 → 采样/ADC → 数字 FIR/特征/模型 → DAC/保持/重建的路径，连接增益、带宽、噪声、动态范围、量化、时钟抖动与最终任务误差。先用解析与数值模型，再选择小信号 SPICE 对照；不要求购买仪器或完成晶体管级 ADC/PLL。

| 节点 | 实验步骤与交付物 | 验收标准 |
| --- | --- | --- |
| MIX-1 信号链与转换合同 | 用正弦/双音/阶跃生成器串接受限增益、RC 滤波、理想采样、8/12 位 ADC 和零阶保持 DAC；交付单位/幅度/采样率合同、频谱与误差预算 | ADC 先定义范围 [-1,1)、Δ=2/2^B、码 k=clip(floor((x+1)/Δ),0,2^B−1)、重建 -1+(k+0.5)Δ；范围内量化误差 ≤Δ/2，溢出计数另报；在阈值两侧/端点/零附近测试，NaN/Inf 明确拒绝；说明采样后滤波不能恢复已混叠信息 |
| MIX-2 噪声与时钟影响 | 分别加入放大器带宽/饱和、输入噪声和采样时刻抖动，再联合扫描；选 RC 与有限带宽放大模型做 SPICE 对照。交付频响、SNR/失真、谱分析设置和敏感性报告 | 每次先只改一个因素，零噪声/零抖动回到基线；频谱窗、采样数、信号/噪声功率口径固定；小抖动下与 e≈x'(t)·δt 对照，时刻非单调等非法配置明确拒绝；不同噪声项不无条件按功率相加 |
| MIX-3 接数字计算与感知 | 将相同采样码输入 HET 的定点 FIR/RTL 或 EMB 小分类器，比较理想、量化、带噪与带抖动输入；交付共同向量、逐层误差和任务质量报告 | 定点结果按 ARITH 舍入/饱和合同与独立整数参考一致；传感误差、数字数值误差和模型质量分别报告；关闭扰动恢复相应基线，开启扰动按预定质量预算判通过或失败；不把模拟链质量下降误判为 GEMM 电路错误 |

ADC 合同仅为原创理想量化器，包含饱和行为；它不等于 NPU v0 的 INT32 回绕语义。SPICE、离线采样向量和 RTL 分层验收，不要求先做实时数模联仿；物理 jitter、ENOB、线性度和芯片功耗需相应器件模型或实测证据。阅读接 SIG/CIR，并参考 [MIT 数字集成电路的时钟与电路约束](https://ocw.mit.edu/courses/6-374-analysis-and-design-of-digital-integrated-circuits-fall-2003/)。

### 六项补强的共同交付与学习验收

### RT 实时系统

课程依次为：① 软/硬/firm 实时、释放时刻、周期/最小到达间隔、相对截止期、抖动与最坏执行时间 WCET；② 单核可抢占固定优先级、RM、EDF、响应时间分析；③ 临界区、优先级反转、优先级继承/天花板、死锁与阻塞上界；④ 中断/缓存/分页/非抢占设备、准入、超载降级、端到端数据年龄与控制稳定性。RTOS 任务/信号量/定时器为机制认知；首次实验自写离散事件模型，可选 RTOS/QEMU 移植后置，不要求安装新系统。

| 节点 | 实验步骤与交付物 | 验收标准 |
| --- | --- | --- |
| RT-1 时限与调度 | 建立单核、零开销、零抖动、独立可抢占周期任务模型，先 D=T、同步释放；固定同刻事件顺序为完成/解锁 → 到期检查 → 释放 → 选取，恰在截止期完成算及时。对比 RM/EDF，交付任务表、甘特图、响应时间和错期账本 | 对任务 (C,T,D)=(2,5,5)、(4,7,7)，RM 中低优先级首任务在 t=7 错期；固定优先级递推 R_i^(0)=C_i、R_i^(k+1)=C_i+Σ高优先级j ceil(R_i^k/T_j)C_j，得 R_2=8>7。EDF 在上述假设下 U=34/35≤1 可调度，仿真 [0,35] 与理论条件一致；再造 U>1 的超载反例；RT-1 错期仅记账且继续执行，用 job ID 区分重叠任务，后续才比较丢弃策略。任务执行量守恒、同优先级确定性 tie-break、无负剩余时间；有限轨迹无错期不能单独当无界证明 |
| RT-2 共享资源与反转 | 固定 H>M>L；L 在 t=0 获得唯一互斥锁并需 3 单位 CPU 后解锁，H 在 t=1 到达、持同锁执行 1 单位且绝对截止期为 5，M 在 t=1 到达并执行 4 单位、不用锁。对照无继承/有继承，交付调度器、锁所有权/有效优先级轨迹、手算与测试 | 无继承 H 在 t=8 完成，有继承在 t=4 完成；解锁后恢复有效优先级，唤醒无丢失且任一时刻仅一个持有者。先限单锁无嵌套，继承不消除锁内工作；若扩展阻塞响应时间分析，须先证明 B_i 的来源与协议假设，不能将任意观测最大阻塞直接当上界；另列嵌套/死锁为后续范围 |
| RT-3 控制与推理分层 | 在 EMB 二维仿真或原创周期控制模型中，将有界 CPU 控制任务和可超时的推理任务分离；模型中加入非抢占 NPU 队列、排队/搬运成本、旧响应与抖动。交付准入/丢弃规则、数据年龄合同、过载/超时/恢复轨迹与稳定性对照 | 运行前固定控制周期、时限、队列上限及过期结果策略；正常配置的控制输出在声明模型内达标，超载样例必须触发预定拒绝/降级，过期/旧 epoch 结果不得作用于新控制周期。丢弃或沿用动作的条件用所选动力学验证，不能默认“保持上次动作”总安全；不可证明的配置明确不保证时限 |

RT-1 公式只用于该独立单核模型；有锁、自挂起、抖动、多核或非抢占加速器时须重新分析。RT-3 初版仅在外部队列取消未派发任务，已派发 v0 任务按原规范完成或复位取消，不新增抢占/中断 ABI。宿主平均/p95、一次最大耗时、QEMU 墙钟和模型 WCET 分列；真实系统硬实时需实际调度/硬件及上界证据。学习者须能预测一次错期，解释继承的局限，并在增加一个不可抢占区后重新判断保证范围。阅读入口：[CMU 实时系统分析讲义](https://www.cs.cmu.edu/~aldrich/courses/654-sp07/slides/23-realtime.pdf)，用于基本模型与分析方法，不将其历史平台建议作为当前通用限制。

### MM 多模态与表示学习

课程依次为：① 表示、归纳偏置、不变性/等变性、监督/自监督目标、坍塌与线性探测；② 图像/文本/音频的配对、语义等价、负样本与增强；③ 双编码器、归一化 embedding、温度、双向对比损失与跨模态检索；④ 早期/后期融合、交叉注意力、缺失模态、冲突与时序对齐；⑤ 小编码器量化、相似度/索引与设备边界。先原创图形—短描述双模态，音调—描述为选修第三模态，不以下载大模型或训练视觉语言大模型为前置。

| 节点 | 实验步骤与交付物 | 验收标准 |
| --- | --- | --- |
| MM-1 表示与共同资产 | 生成 32×32 色块/形状图及描述，定义颜色、形状、位置等语义和 scene ID；同一场景的增强/同义描述放同一划分。比较原始像素/手工特征、随机编码器和小监督编码器的冻结表示，交付生成器、配对清单、划分/增强规则、线性探测和近邻结果 | 训练/验证/测试按场景分组无交叉；另留属性组合迁移集，明确已见属性与未见组合，不能混报同分布与组合泛化。线性探测只训练探测头，预处理/表示学习只看训练集；标签改变型增强被拒绝；零向量归一化有定义，报告表示方差/检索结果，不凭二维可视化判定语义正确 |
| MM-2 对齐与跨模态检索 | 用小图像编码器与词/属性文本编码器从随机初始化学习共享空间；在每批语义不同的一一配对样例上，s_ij=normalize(v_i)·normalize(t_j)/τ、τ>0，双向交叉熵用 log-sum-exp 实现。交付推导、float64 微型参考、梯度检查、双向检索和错配训练消融 | 数值/梯度误差按 DLE-1 的相对归一化 ≤1e-6 检查；交换模态后对称目标不变。若同语义多正例同批，必须改用明确的多正例目标，不把等价描述当负例；评估相关集合覆盖全部正确匹配，Recall@1/5 的分母、gallery、平分处理固定。至少三个种子，与随机/手工特征同划分比较；目标质量在训练前设定，未达到记失败，不要求对比学习必胜 |
| MM-3 融合 故障与部署 | 在同任务比较单模态、后期融合和一个小交叉注意力方案，注入缺失/错配/矛盾描述；有音频时另验时间戳偏移。冻结模型后量化一个线性层，复用 DEP 的计划/整数参考并接检索或 Agent。交付消融、拒答/覆盖率、逐层误差及内存/延迟账本 | 同输入/信息权限和开发预算；缺失模态用显式掩码，阈值只由验证集选择；无输入时拒绝，不把拒答样本从任务分母删去。量化与 FP32 质量分列，整数输出按合同一致；只支持的 Linear 上设备，归一化/Softmax/检索仍在 CPU，QEMU/RTL 未接入保持待验证，不宣称多模态 LLM 已完成 |

最小配方上限先设总计 2,000 个场景、小编码器 ≤1M 参数、最多两个模态，沿用文末电路与小模型预算；先跑小批检查再扩大。正式实验须锁定具体场景数/划分、gallery 和质量阈值；本轮不填写模型成绩。学习者须解释“配对好不等于组合泛化”，构造一个错误负样本并修正，再改变一种模态噪声复验。参考 [CLIP 原始论文](https://proceedings.mlr.press/v139/radford21a.html) 的图文对齐思路；这里是原创微型实验，既不复制其数据/权重，也不等同其规模或能力。

### CAUSE 因果推断

课程依次为：① 相关、预测、干预与反事实，潜在结果与平均处理效应 ATE；② 因果 DAG、结构因果模型 SCM、混杂/中介/碰撞点、d-separation 与后门；③ 一致性、无干扰、可交换性、positivity/重叠、识别与估计，随机实验、标准化与逆概率加权；④ 未观测混杂、敏感性、选择偏差与迁移；⑤ 已知 SCM 的反事实和有边界的策略评估。工具变量/前门/双重稳健与因果发现为后续阅读，不要求完整实现；日志相关和模型解释分数不能自动给出因果图。

| 节点 | 实验步骤与交付物 | 验收标准 |
| --- | --- | --- |
| CAUSE-1 观察与干预 | 构造二元 SCM：Z~Bernoulli(0.5)，P(A=1 given Z=0/1)=0.2/0.8，P(Y=1 given A,Z)=0.1+0.4Z+0.2A；各节点用独立均匀外生噪声阈值生成。交付 DAG、全联合概率表、观察差和 do(A) 干预枚举 | 概率合法且归一化；精确枚举观察差 E[Y given A=1]−E[Y given A=0]=0.44，ATE=0.20，绝对误差 ≤1e-12；用 do 固定 A 时删除其入边，不重新条件化 Z。有限采样另报误差，不用样本碰巧接近替代枚举校验；能解释高预测准确率不识别干预收益 |
| CAUSE-2 识别与估计 | 先在已知图上说明调整 Z 的有效性，再比较不调整、标准化和 IPW；使用精确倾向概率作基准，再用训练数据估计倾向。加入碰撞点误调、缺乏重叠和隐藏 Z 场景。交付识别假设、估计器、有效样本/权重诊断与重复试验 | 在全概率表上标准化/IPW 均还原 0.20、误差 ≤1e-12；至少 30 个合成重复样本报告偏差/RMSE/区间及覆盖，n/种子/方法预先锁定，不强制每次区间覆盖真值。倾向为 0/1 或目标群体无支持时报告不可识别/不支持，不能静默裁剪后宣称估计原 ATE；截权若采用须报告偏差与目标变化 |
| CAUSE-3 反事实与决策边界 | 在已知 SCM 中固定同一个体外生噪声重放 A=0/1；仅有观察时用相容外生噪声的后验，不能随意重抽为“同一个人”。再构造两个模型：U~Bernoulli(0.5)，均 A=U，一者 Y=A，另一者 Y=U；把有成本干预接有限 Agent 模拟世界。交付反事实、不可识别反例、干预成本/收益与策略轨迹 | 两模型观察上均 A=Y 且各 0/1 概率各半，但 ATE 分别为 1 与 0；据同一观察分布不能唯一判断因果效应。已知 SCM 的策略只用允许观察，在独立留出外生样本上执行策略选择的干预，按收益减成本评分，与随机策略作同环境对照；若用干预日志离线估值，另验已知倾向概率/IPW 和重叠条件；不借隐藏噪声作策略输入。模型未知/重叠不足时明确拒绝因果保证；权限与工具边界仍由程序执行 |

该路线只在原创有限合成世界验证推断，现实因果结论还需要领域假设与合适研究设计；不开展真人干预。学习者须分清“目标是否可识别”和“估计是否精确”，并在更改一条边或隐藏 Z 后重新写出可回答的问题。阅读入口：[Brady Neal 因果推断课程](https://www.bradyneal.com/causal-inference-course)，其中概率基础、图、识别/估计与反事实按需要接入；本项目公式和小案例为原创教学设计。

## DESIGN 从需求出发的整体设计取舍

这是一个综合实验、四个递进检查点，不是新平台或第四条必修专业。复用 SELECT/AGQ 的本地受限任务助手：限定资料检索、计算器、实验结果查询；先用规则/CPU 建协议，再用自训练小模型，最后比较量化/设备后端。三门新专题作为需求变体：有控制时限才接 RT，有图文输入才接 MM，需要预测干预后果才接 CAUSE；首轮无需一次完成三条专题。

先使用下列教学需求卡，实施前在 DESIGN-1 锁定版本。数字为项目设计目标，尚无测量证明；修改需求必须新建版本、说明理由并重验，不能事后改低标准掩盖失败。

| 需求 | 首轮目标与测量范围 | 证据与判定 |
| --- | --- | --- |
| 功能与质量 | 至少 30 个按模板/场景隔离的留出任务；目标成功率 ≥90%；每任务最多 8 次工具调用 | 用独立执行器判终态；拒答/失败/超时计入分母；三种子模型结果分别列出，所有种子均须达标才判该候选质量通过；规则与模型分列 |
| 权限与恢复 | 非授权调用执行数为 0；已声明故障集逐项检测/处置 | 坏包、越界路径、工具超时、重复请求、旧版本/旧 epoch 结果及断点恢复；未知副作用按 STATE 查询/对账，不能重复执行后假称恰好一次 |
| 内存与存储 | 目标运行时权重 ≤16 MiB、峰值工作区 ≤8 MiB；初版单任务、队列最多 4 项 | 静态张量生命周期和实际分配/峰值对账，索引/文本/KV/日志各注明是否另设预算；总量不能靠漏项过关；宿主解释器/OS RSS、训练开销另列，不能拿宿主 RSS 当片上 SRAM |
| 响应与负载 | 在 DESIGN-1 固定的宿主/线程配置下，CPU 服务端到端 p95 ≤1 秒，软时限；固定到达轨迹、至少 200 次请求 | 包括排队、检索、模型与工具；预热策略和分位数算法固定，超时及未完成率另报，未成功完成的请求按 +∞ 参与此服务目标的分位数，不删除慢请求；初版为教学 QoS，不是硬实时保证。若接 RT，另写硬时限任务合同与分析 |
| 面积与能耗 | 初版无统一毫米平方/瓦特门槛；在有目标库与完整证据后再冻结 PPA 预算 | 无库时只比相同范围的通用综合单元/访存计数；有库后同工艺角/频率/活动/范围比较；未知写未知，不把软件耗时或 MAC 功耗外推全系统能耗 |

工作区之外的索引/文本/KV/日志预算须在第一检查点填成有限上限才能运行；宿主运行成本仍受文末资源档位约束。教学质量/服务目标可能无法由首个小模型满足，届时交付“目标未达标”的证据和修改方案，实验过程可完整但系统验收不能算通过。

| 检查点 | 实施步骤与交付物 | 验收标准 |
| --- | --- | --- |
| DESIGN-1 冻结需求与边界 | 明确用户任务、合法输入/输出、失败代价、负载和部署平台；将上表拆成 REQ ID，区分必须满足与优化项；画任务→模型→算子→运行时→设备→存储路径。交付需求卡、测试划分、资源账本、风险/未知表、验收矩阵 | 每条必须需求有单位、范围、阈值、独立判定方法和责任层；数据/时间/内存分母无歧义，开发与最终测试隔离；目标硬件与宿主/仿真环境分列，需求仍为空的项不能进入该项验收 |
| DESIGN-2 列候选与预测 | 至少比较规则/经典 CPU 基线、同一学习模型的 FP32 CPU、INT8 CPU、INT8 NPU 线性层+CPU 回退；固定各方法信息权限。对模型大小、位宽、分块、缓冲/数据复用列有限候选，作计算/字节/容量/排队账本。交付候选矩阵、预测瓶颈及淘汰理由 | 先检查质量与容量等硬约束再优化；FP32/INT8 误差目标预先固定，设备只用 v0 已支持能力；包含传输、scale/bias、KV、CPU 回退和初始化成本；CPU/GPU/DSP/NPU 的适用性可作 HET 对照，未实测平台不能写成优胜者 |
| DESIGN-3 收集可比证据 | 先完成 G2 单 Linear，再扩大到 M3 模型/M4 任务；保持相同输入与版本，比较参考、优化 CPU 和设备路径；做一个因素一变的消融与超载/坏包故障。交付逐任务原始结果、分层误差、时间/资源和适用 PPA 报告 | 整数/布局正确、任务质量、预算分别判定；完整设备路径仍需 C/QEMU/RTL 各自验收，未实现候选保留待执行。宿主实测、QEMU 功能、RTL 周期和参数估算分栏；周期转时间必须附时钟/存储假设，未校准只能条件推断，不能与 CPU 实测混出“加速倍数” |
| DESIGN-4 做选择并迁移 | 先过滤违反必须约束的候选，再对同证据层的质量/延迟/内存/能耗等作 Pareto 比较；给出一个选择及被放弃方案理由。将内存预算减半或输入长度加倍（二选一），预先预测后重验。交付决策记录、需求追溯表、敏感性/反例、复现包和学习者解释 | 有数据支持选择；不确定/缺测指标不按 0 算，不以综合分掩盖硬约束失败。没有候选达标时正确结论为“当前不可行”；CPU 方案胜出可接受，不强迫使用 NPU。迁移后重验相关质量/资源/时限，说明结论是否改变；独立学习者须能复现一个比较并解释取舍，未试读单列待验证 |

DESIGN 结论按证据层交付：参数预测、单层验证、模型验证、完整任务验证。G2 软件阶段不能替代完整设备或 M4；规格比较完成也不能标成实现完成。除重用既有矩阵/模型/任务外，交付需求清单、决策记录和原始数据索引，均放入已有 `docs/`、`labs/` 等目录，不另建一级目录。NPU 不支持的能力明确后置，不为通过实验暗改设备 ABI。

## 三门专题与综合实验的共同交付

每个节点继续采用“小课 → 手算/预测 → 最小实验 → 故障/反例 → 迁移”五步。RT 保存事件顺序、时限/成本假设与错期轨迹；MM 保存配对关系、正例集合、划分与消融；CAUSE 保存图/结构方程、识别条件与目标效应；DESIGN 用 REQ ID 关联这些证据与原契约、资产哈希和预算。建议先轻量参考档完成 RT/CAUSE/需求卡，再用小模型档开展 MM；短跑资源实测后再扩大规模，所有完整实现和学习者记录均待交付。

## 完备性的边界

补全后，规划连起“数学/信号 → 器件/电路 → 数字/物理/系统 → 机器学习/生成模型 → 感知/推理/控制 → 服务/Agent”，并用实时约束、多模态表示与因果干预补充系统边界，通过 DESIGN 把需求与实现决策连起来。这能支持全景理解与有限系统实践；不能据此承诺独立掌握先进制程、模拟/RF 全领域、工业 EDA 签核、完整标准控制器、通用机器人或前沿大模型训练。

完成标准应看学习者能否解释接口、实现小系统、定位跨层故障并说清结论边界。后续优先兑现 PRA/DEP/DLE 的证据，再按兴趣深入 CHIP、EMB、SCALE；继续增加目录不会代替这些能力。
