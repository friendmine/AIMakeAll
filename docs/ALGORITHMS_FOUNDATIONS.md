# 算法与数据结构知识体系

更新：2026-11-17。以 [MIT 6.006 Spring 2020](https://ocw.mit.edu/courses/6-006-introduction-to-algorithms-spring-2020/) 为基础参考，连接编译器、运行时、操作系统和 Agent。`AL01–AL10` 是本项目模块编号，不对应课程讲次。**当前完成知识与实验规划，新增实现均待完成。**

## 学习目标与知识地图

不仅能写出可运行程序，还要说明结果为什么正确、规模扩大后成本如何变化，以及数据结构与内存布局如何影响真实执行。主题参考官方[课程安排](https://ocw.mit.edu/courses/6-006-introduction-to-algorithms-spring-2020/pages/calendar/)，实验为项目原创设计。

| 模块 | 核心知识 | AIMakeAll 实验 | 验收标准 |
| --- | --- | --- | --- |
| AL01 | 问题建模、不变量、归纳证明、时间/空间复杂度、最坏与摊还成本 | 给 GEMM、分块计划和任务队列建立成本模型 | 解释输入规模、操作次数及辅助空间；区分复杂度、估算和实测时间 |
| AL02 | 数组、链表、动态数组、栈、环形队列及接口设计 | 有界任务队列与张量描述符容器 | 空/满/回绕/扩容行为明确；这一模块先做单线程，并发另由 OSTEP 验收 |
| AL03 | 排序、二分、比较模型、计数/基数方法及适用条件 | 对模型张量区间排序，查找指定偏移所属张量 | 重复值、边界和非法区间有测试；整数排序前提与额外空间明确 |
| AL04 | 哈希、冲突处理、负载因子、期望与最坏成本 | 编译器符号表、文档内容去重索引 | 冲突注入下仍正确；内容去重不能仅因短哈希相同就判定相同 |
| AL05 | 搜索树、平衡、遍历与有序查询 | 用小型有序索引查找空闲内存区间 | 插入/删除后保持不变量；与简单线性实现对照 |
| AL06 | 二叉堆、优先队列、稳定次序与 Top-k | 工具超时队列和检索候选 Top-k | 相同优先级结果可重现；更新/取消不遗留失效任务 |
| AL07 | 图表示、BFS/DFS、可达性、环检测与拓扑排序 | 计算图依赖检查和执行次序生成 | 所有依赖先于使用；有环、缺输入、重复名称时拒绝；不遗漏共享子图 |
| AL08 | 加权路径、松弛、Dijkstra、Bellman-Ford 与多源问题 | 在自造小图比较不同执行路径的估计成本 | 明确权重条件并与穷举对照；最短路径示例不冒充完整硬件调度器 |
| AL09 | 动态规划、状态设计、递推、重建与伪多项式成本 | 矩阵链括号化或小规模切分策略选择 | 与小输入穷举一致；数学等价不代表浮点舍入或量化语义不变 |
| AL10 | 复杂度边界、问题归约、精确与启发式算法的取舍 | 比较简单调度启发式和小图穷举基线 | 报告解质量、时间和内存；不把启发式称为全局最优 |

## 三个应用入口

- **AI 编译**：AL04 建立符号与张量表，AL07 检查 DAG，AL03/AL05 组织内存区间，AL01 度量计划成本。先用顺序调度和保守内存分配，再研究复用与优化。
- **系统与运行时**：AL02/AL06 支撑排队、超时和取消；锁、原子性及生命周期由 [OSTEP 模块](OSTEP_FOUNDATIONS.md) 补齐。
- **Agent 检索**：AL03/AL04/AL06 支撑倒排索引与候选排序；相关性和答案质量由 [检索可靠性专项](ENGINEERING_BRIDGES.md) 评估。

数学复杂度之外，还要结合 CSAPP 的缓存和局部性。链表与数组即使操作次数接近，其访问和分配成本也可能不同；用相同数据规模分别记录时间和空间，不据单次计时下结论。

## 学习顺序与交付

数学基础按 [MATH-E1–E6](UDL_FOUNDATIONS.md) 补深，尤其用 E1 的逻辑、归纳和不变量解释 AL01/AL07，用 E2/E4 的矩阵与条件数理解数值问题。AL03 的张量区间检查接 [SW-E2](SYSTEMATIC_VERIFICATION.md)，AL04/AL06 的请求索引与任务队列接 [STATE-E2/E4](ENGINEERING_BRIDGES.md)。这些均是既有领域内的待实现子实验。

先学 AL01–AL04，再学 AL06/AL07，完成一个带非法输入检查的计算图排序器；AL05/AL08–AL10 随内存规划和优化问题深入。不要把读完算法课程设为开始硬件实验的门槛。

每个实验交付：接口与输入约束、不变量或正确性说明、复杂度分析、可运行实现、边界用例和与简单参考实现的对照。首项为 **AL07 计算图拓扑排序**，输入可以是原创的几节点静态图，不需要模型框架或 MLIR。
