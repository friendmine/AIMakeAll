## 三条课程共用的首个实验契约

这份契约仅适用于新的教学 FIFO，**不修改现有 MAC 的异步复位和 NPU v0 ABI**。首次实现采用单时钟、深度 4、数据宽度 8、无组合直通的队列；参数化作为后续练习。

- 接口为输入 `in_valid/in_ready/in_data`、输出 `out_valid/out_ready/out_data`、时钟及高有效同步复位 `rst`。
- 非复位时，`in_ready = count < 4`，`out_valid = count > 0`。输入/输出分别仅在上升沿前 `valid && ready` 为真时发生传输；用沿前状态判断，避免测试台与 DUT 竞态。
- 满时即使同沿有读出也不接受写入，空时不允许输入直通到输出。中间占用时可同时读写，计数保持；连续有效输出为当前队首。
- 输入端遇到 `valid && !ready` 必须保持 valid/data，直到接收或复位；输出端同理保持队首数据，直到读出或复位。`out_valid=0` 时数据不作有效性要求。
- `rst=1` 时 ready/valid 均置 0；在复位上升沿清空指针与计数，该沿没有传输，未消费数据视为取消。不要求清零不可见的存储数组。首次使用前必须经历复位沿。
- 非复位沿满足 `count_next = count + accepted_in - accepted_out`，且占用在 0–4 之间。测试必须区分“尝试发送”和“实际接收”，禁止把 full 时未接收的数据算作丢失。

共同交付计划：接口说明、独立 Python 队列参考、可综合 RTL、逐周期输入/接收/发送记录、波形、定向/随机测试、覆盖表、形式性质和综合报告。DV 课程负责检查这些要求，SIM 课程定义如何对齐时间和轨迹。上述均尚未实现。

## 时序与 CDC 的证据边界

基础 RTL 仿真不模拟真实亚稳态的模拟电压行为。同步器结构、异步 FIFO 指针跨域、复位释放和约束需单独检查；逐比特同步普通多位数据不能自动保证同一字的一致性。

DD07 先报告可综合性和逻辑资源，再在明确的工艺库、PVT、时钟/IO 假设下报告 STA。时序例外必须有功能理由，不能通过随意 false path 或 multicycle 掩盖问题。没有布线寄生的结果不称作布线后时序；OpenSTA 报告也不单独证明 CDC 正确或可量产。

## DD07/ENG03 深化：功耗、能耗与面积权衡

PPA-E1–E6 归入已有领域 04/16/18，连接 ARCH-E6、PERF-E6、MEM-E6 与 ENG03。PPA 指功耗、性能、面积，本组另按工作量计算能耗；全部待实现。实验在电脑内完成，先用 MAC/FIFO 等小模块，不要求制造芯片。没有适用库或活动证据时，保留缺项，不能补造瓦特、焦耳或 MHz。

两层交付：先完成 PPA-E1/E2 的比较契约、综合及适用的 STA；库功耗表、工具支持和可追溯活动具备后，再开展 E3/E4。活动分析优先核对门级 VCD 与网表范围；如果只能传播输入活动假设，结果必须标记估算并扫描假设。宏存储没有功耗/面积模型时单列，不能因黑盒未计入就宣称总芯片更省电。

默认用相同目标频率和满足时序的候选比较，再单独研究各自可实现频率；总能量受功率与任务时间共同影响。固定时间窗与固定完成工作量的结论分开，MAC 操作次数是否将乘加算作两次操作须明示。逻辑估算、映射后分析、含寄生的物理分析逐级标记；不由软件模拟的宿主用电推算目标 NPU 用电。

真实时钟门控是后续独立实验，需要合适的集成门控单元、使能稳定性/时序约束和验证；第一组先做数据路径隔离及寄存器使能。参考 [OpenSTA 功耗与 VCD 示例](https://openroad.readthedocs.io/en/latest/main/src/sta/doc/Examples.html#power-analysis)，实施时锁定工具、Liberty、约束和输入轨迹；本轮未引入工艺库或产生 PPA 数值。
