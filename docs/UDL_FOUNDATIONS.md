# Understanding Deep Learning 知识体系与项目实验

更新：2026-11-17。参考 Simon J. D. Prince 的 *Understanding Deep Learning*，以 MIT Press 2023 年版的 **21 章及附录 A–C** 为基准。[出版社介绍](https://mitpress.mit.edu/9780262048644/understanding-deep-learning/) · [官方目录](https://mitp-content-server.mit.edu/books/content/sectbyfn/books_pres_0/15055/prince_toc_.pdf)

UDL 为 AIMakeAll 提供模型、学习算法和评估方法基础，与 [CSAPP 系统基础](CSAPP_FOUNDATIONS.md) 并行：理解模型为什么能学习，再把计算图交给运行时、QEMU 和 NPU。下文是原创学习组织与实验设计，不是原书翻译或官方习题解答。**当前完成章节级知识映射，新增实验均待实现。**

[全景补全课程](CHIP_AI_COMPLETENESS.md) 新增 SIG 微分方程/信号系统、CLA 传统机器学习/经典 AI、DLE 推导/独立校验/模型比较及 EMB 感知/估计/控制路线。它们接在现有 MATH、UDL 章节上；DLE 三个节点复用原实验，均待实现。

## 2. 全书知识地图

编号 `UDL01–UDL21` 与书中章号对应；下列概念按本项目需求归纳，实验与验收标准均为本项目设计。课程原有 `00–16` 和 `CS01–CS12` 编号保持不变。

### 表达、学习与评估

| 模块 / 章节主题 | 学习重点 | 原创项目实验 | 验收证据 |
| --- | --- | --- | --- |
| UDL01 / 引言 | 预测、分布学习、决策的任务区别；数据与目标的关系 | 将文本续写、工具调用、矩阵推理分别描述为任务、输入、输出、指标 | 解释预训练、SFT、RL 的不同，以及硬件加速与学习算法的边界 |
| UDL02 / 监督学习 | 参数化模型、样本、目标值与训练目标 | 用自生成数据训练线性回归，比较解析解与迭代解 | 保存数据种子、参数误差与独立测试误差 |
| UDL03 / 浅层神经网络 | 仿射变换、非线性、隐藏单元与函数表达 | 手写单隐藏层网络，拟合一维分段函数 | 标注各层维度，比较不同宽度的误差与参数量 |
| UDL04 / 深层神经网络 | 函数复合、深度与宽度、批处理矩阵形式 | 将逐样本 MLP 改成批量矩阵实现，分解为 GEMM 与逐元素运算 | 两种实现输出一致；列出每层乘加次数及激活存储 |
| UDL05 / 损失函数 | 概率模型与似然、回归/分类目标、交叉熵 | 实现稳定的 log-softmax 与 token 交叉熵，检查标签移位和 padding mask | 大幅值 logits 下输出有限；与可信参考对照；无有效 token 时明确报错或跳过 |
| UDL06 / 模型拟合 | 梯度下降、小批量、动量、Adam 与超参数 | 在同一小数据集比较 SGD/Adam，记录学习率与批量影响 | 使用相同划分和计算预算；训练曲线、配置及失败运行可追溯 |
| UDL07 / 梯度与初始化 | 链式法则、反向传播、梯度尺度和初始化 | 为小 MLP 手推并实现反向传播，再与有限差分和自动求导对照 | 在避开非光滑点的小输入上通过约定误差检查；展示不合适初始化的影响 |
| UDL08 / 性能度量 | 拟合误差与泛化误差、模型容量、选择超参数 | 按文档划分文本数据，建立 bigram 与 Transformer 的验证评估 | 测试集不参与调参；损失按有效 token 加权；报告多个种子的波动 |
| UDL09 / 正则化 | 显式与隐式约束、过拟合及训练改进方法 | 对权重衰减、dropout、早停分别做受控实验 | 固定其他变量，保存训练/验证差距；不以训练损失下降代替泛化改善 |

### 网络结构

| 模块 / 章节主题 | 学习重点 | 原创项目实验 | 验收证据 |
| --- | --- | --- | --- |
| UDL10 / 卷积网络 | 局部连接、权重共享、平移性质与采样 | 自生成小图像，比较直接卷积与展开后 GEMM | 对齐 padding/stride 与输出；记录展开的额外内存，作为 NPU 扩展候选 |
| UDL11 / 残差网络 | 跳连、梯度传播、归一化及深层训练 | 对比相同宽度网络的残差开关，另比较归一化位置 | 保存梯度范数与训练曲线；区分 BatchNorm、LayerNorm 和 MiniMind 的 RMSNorm |
| UDL12 / Transformer | 自注意力、多头、位置、掩码与不同结构 | 自写小型 decoder-only 模型，检查注意力矩阵及逐步生成 | 修改未来 token 不影响过去位置输出；KV cache 开关对照；每层维度可追踪 |
| UDL13 / 图神经网络 | 图表示、消息传递、聚合与置换性质 | 在原创小图上做节点分类，作为结构化实验数据的研究练习 | 节点重编号后输出相应重排；训练/测试图明确隔离；不把 GNN 当成 Agent 必需组件 |

### 生成模型与决策扩展

| 模块 / 章节主题 | 学习重点 | 原创项目实验 | 验收证据 |
| --- | --- | --- | --- |
| UDL14 / 无监督学习 | 数据分布、生成目标及不同质量指标 | 在可计算真分布的二维数据上比较生成样本与留出数据 | 同时检查覆盖与拟合误差；说明文本似然与实际任务质量的区别 |
| UDL15 / 生成对抗网络 | 生成器/判别器、交替优化与训练失衡 | 二维多峰数据的小 GAN，观察模式缺失 | 多种种子下记录模式覆盖及失败；仅作为生成模型选修 |
| UDL16 / 归一化流 | 可逆映射、变量变换与密度计算 | 手写简单可逆变换，计算正逆过程及密度 | 检查逆变换误差和 Jacobian 项；与已知分布对照 |
| UDL17 / 变分自编码器 | 潜变量、近似推断、ELBO 与重参数化 | 自生成低维数据的 VAE，拆开重建项与 KL 项观察 | 分别保存两项和样本；不将 ELBO 直接标为精确对数似然 |
| UDL18 / 扩散模型 | 加噪、去噪、训练目标与迭代采样 | 二维数据的简化去噪模型，对比采样步数 | 明确噪声日程及随机种子；记录分布质量与采样成本，作为后续算子负载 |
| UDL19 / 强化学习 | 状态、动作、奖励、回报、价值与策略学习 | 先在有限小环境实现表格策略，再研究受限工具选择 | 与随机/规则策略比较回报和成功率；检查奖励漏洞，Agent RL 单独立项 |

## 3. 数学和概率基础

| 模块 / 附录 | 项目需要掌握 | 基础练习与检查 |
| --- | --- | --- |
| UDL-A / 符号 | 标量、向量、矩阵、张量及参数/样本索引 | 给一个 batch 的 embedding、注意力和线性层逐一标注形状 |
| UDL-B / 数学 | 函数、组合计数、矩阵运算与求导 | 推导线性层前向和梯度的维度；检查转置、广播及批量累积 |
| UDL-C / 概率 | 随机变量、分布、期望、高斯、采样及分布差异 | 用离散小分布计算熵、交叉熵和 KL；验证采样频率，处理零概率边界 |

先补到能理解当前实验的程度。开始 MLP 需要矩阵乘法和链式法则；理解交叉熵需要概率与对数；VAE、流和扩散再深入概率推导，不阻塞首版 LLM。

### 领域 01 深化：数学基础子实验

MATH-E1–E6 为领域 01 内的项目原创编号，不是 UDL 附录新增章节，也不新增一级课程。它们补深 UDL-A/B/C、AL01、ENG01 和 SIM07，全部待实现。先用小尺寸、可手算或高精度对照的问题，不要求购买计算设备。

| 子实验 | 知识范围 | 实验产物 | 验收要求 |
| --- | --- | --- | --- |
| MATH-E1 离散数学与证明 | 命题逻辑、集合/映射、计数、归纳、不变量、图与状态机 | 将 FIFO 占用/顺序及 DAG 依赖写成数学命题，给归纳步骤和反例 | 明确前提、状态与量词；有限枚举不是无界证明；连接 AL01/AL07、DD03 与 DV05 |
| MATH-E2 线性代数 | 向量空间、线性映射、秩、范数、正交投影；分解概念 | 比较矩阵变换、转置布局与投影；构造满秩和秩亏的小线性系统 | 形状和子空间关系可解释；检查残差与解是否唯一；不能以训练损失小代替参数可辨识 |
| MATH-E3 微分与反向传播 | 偏导、梯度、Jacobian、链式法则、向量化与广播 | 手推 Linear/小 MLP 梯度，对照有限差分和自动求导 | 在光滑点扫描差分步长并报告误差；避开或说明不可微点；广播归约和 batch 平均正确 |
| MATH-E4 优化与条件数 | 梯度下降、学习率、曲率、尺度与条件数、正则化 | 同一小型最小二乘问题用 QR/SVD 参考求解与梯度下降，对比缩放前后收敛；先满列秩再秩亏 | 不显式求逆作为默认解法；目标函数保持一致；分开记录残差、迭代次数和误差，解释发散/非唯一解 |
| MATH-E5 概率与信息量 | 条件概率、Bayes、期望/方差、似然、熵、交叉熵、KL 与采样 | 在已知离散分布上计算指标并采样，连接 next-token 交叉熵 | 对数底与单位一致；正确处理零概率和无限 KL；区分概率、logit、token 平均与困惑度 |
| MATH-E6 数值与统计 | 舍入/消去、稳定算法、病态问题、误差传播、独立样本与区间 | 比较稳定/朴素 softmax、累加与量化误差，再对多种种子的小实验报告波动 | 极值不产生未解释 NaN/Inf；容差随尺度说明；统计波动与模型偏差分开，不用同一确定性重放充当独立重复 |

最短路径：做 C/INT8 与 FIFO 时按需完成 E1、E2、E6 的整数/布局部分；进入 MLP 前补 E3，训练前补 E4/E5。E4 复用同一原创合成数据、目标函数与种子，分别保存满秩/秩亏、缩放和学习率配置；缩放后需映射回原变量再比较参数。数值库仅作经过记录的对照，不把调用库等同于理解推导。

每项交付手算或推导、可执行小程序、固定输入、边界/反例与误差报告；当前只完成设计。理论入口继续使用 UDL-A/B/C 与 [算法课程](ALGORITHMS_FOUNDATIONS.md)，量化和统计分别汇入 [ENG01](ENGINEERING_BRIDGES.md) 与 [SIM07](SIMULATION_CREDIBILITY.md)。

## 4. 从理论到 MiniMind 和 NPU

### 训练闭环

优先按 UDL02–UDL09 建立可解释的小模型训练闭环，再进入 UDL11/UDL12。一次训练必须能回答：数据如何划分，目标如何生成，损失对哪些位置求平均，梯度如何更新，验证指标为什么可信。

对接 [MiniMind 阅读路线](MINIMIND_INTEGRATION.md) 时，UDL04/UDL11/UDL12 对应模型层，UDL05 对应标签与 loss mask，UDL06/UDL07 对应优化与初始化，UDL08/UDL09 对应验证与泛化。RoPE、GQA、RMSNorm、门控 MLP 等具体选择按固定源码逐项补充，不假定书中的通用示例与 MiniMind 完全相同。

SFT 从自己训练的预训练权重继续学习；它是监督训练。学习 UDL19 有助于理解后续奖励与策略优化，但不能将其直接等同于 MiniMind 的某个具体 RL 算法，需另查实现与原始论文。

### 算子与数值闭环

以批量线性层 `Y = XW + b` 为桥梁：标出 `X[M,K]`、`W[K,N]` 和 `Y[M,N]`，对接本项目 [GEMM 规范](../specs/npu-v0.md)。模型库若以 `[N,K]` 保存权重，导出时必须显式转换布局；bias、scale、非线性与残差由运行时另外处理，不能隐含在首版 GEMM 中。

首版 NPU 负责 **INT8 线性层推理**，训练和反向传播留在宿主机；Softmax、归一化、位置变换与其他非线性先留 CPU。卷积、图计算及扩散只扩展知识和候选负载，不扩大当前 NPU 指令范围。

量化与部署作为项目专项补充：依次比较 FP32 单层、量化单层、全模型 logits、验证损失和最终任务。与 CS02 的整数语义、CS05 的性能测量、CS06 的局部性、CS09 的内存生命周期共同学习。校准数据来自训练集或独立校准划分，不使用最终测试集调量化参数。

### 质量与系统性能闭环

UDL 的模型表现和计算机系统的执行性能分别记录。固定 tokenizer、测试数据、有效 token 统计及推理配置后，再比较困惑度；改变 tokenizer 的模型不直接用困惑度数值排名。延迟、吞吐、内存、量化质量和 Agent 成功率也分别报告，不能用其中一项替代其余指标。

Agent 主线先走规则协议验证、工具调用 SFT 和独立任务评估，再考虑 RL。UDL08/UDL21 支撑评价与能力边界，CS08/CS10–CS12 支撑工具进程、I/O 和并发。

## 5. 学习顺序与交付门槛

| 阶段 | UDL 内容 | 与现有课程衔接 | 交付门槛 |
| --- | --- | --- | --- |
| 基础准备 | UDL-A/B/C 按需，UDL01–UDL04 | 实验 00 与 CS01/CS02 | 维度清楚，标量/矩阵实现一致 |
| 训练基础 | UDL05–UDL09 | 单元 08–10 | 梯度对照、稳定损失、独立验证及可恢复训练 |
| LLM 核心 | UDL11、UDL12 | 单元 09–11 与 MiniMind | 因果性、残差/归一化、KV cache 对照 |
| 硬件部署 | 回用 UDL04/UDL08，加项目量化专项 | 单元 12–13，M1/M2 的 GEMM | 算子误差、模型质量、搬运成本和性能分别验收 |
| Agent | UDL08、UDL21；UDL19 为后续扩展 | 单元 14–16 | 模板外任务、失败分类和有界工具执行 |
| 广度与研究 | UDL10、UDL13–UDL18、UDL20 | 后续选修与实验报告 | 每项独立小实验，不作为前述里程碑的前置门槛 |

第一组新增实验建议为：自生成数据线性回归 → 小 MLP 手写梯度 → 稳定交叉熵 → 因果注意力。先建立 CPU 小实验，再评估可选加速环境；使用独立环境并记录依赖，不修改 EDA/OpenRAM 环境。

每个实验交付原创说明、实现、配置/数据来源、边界或失败用例、指标与复现命令。当前仅完成知识体系与路线设计，没有新建训练环境、下载数据/权重或运行官方 notebooks。
