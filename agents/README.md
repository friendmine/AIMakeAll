# Agent 主线（待实现）

目标是建立“任务 → 模型决策 → 工具执行 → 观察 → 决策/结束”的可检查循环，推理经统一运行时调用自训练模型。

拟定消息形态：

```json
{"type":"tool_call","name":"calculator","arguments":{"expression":"12 * 7"}}
```

```json
{"type":"final","answer":"结果是 84。"}
```

工具返回单独的 observation，不允许工具内容直接改变执行权限。工具名必须注册、参数必须校验，计算器使用受限语法解析，不能调用 `eval`。首版仅提供计算、限定目录检索和实验结果读取，不执行任意 shell。限制最大步数、单次超时、上下文长度，并记录完整轨迹。

先用规则策略验证循环，再用自训练模型接替决策。两种策略的结果必须分开。非法 JSON、未知工具、参数错误、工具超时、重复调用和达到步数上限，都应有可预测的错误处理。

公开独立任务集、正确答案/成功判据、模型配置、成功率、工具调用合法率与总耗时。最终对照相同模型的 CPU 和 NPU 路径，观察计算加速对整个任务的贡献。详见 [M4 验收](../docs/ROADMAP.md)。
